# 晓得 · 讲得清

> 把「一份长报告」变成「15 页能讲的结构 + 每页口播稿」。
> 一页一个论点、正文不超过 40 字，其余全进讲稿——这是对抗「照着报告搬、一页 500 字」的唯一办法。

## 一、先分清（不做这一步后面全错）

| 概念 | 判定标准 | 处理方式 |
|---|---|---|
| **报告内容 vs 演讲论点** | 报告是信息堆，演讲是一串论点 | 每页只承载一个论点 |
| **页面文字 vs 讲稿** | 页面是提示，讲稿才是要说的话 | 正文 ≤40 字，其余进讲稿 |
| **叙事线 vs 页面堆砌** | 页与页靠逻辑转场，不是目录罗列 | 先定叙事线再分页 |
| **填满 vs 留白** | 模型倾向填满，规则要求删到不能再删 | 逐句问「删了论点还成立吗」 |

**最容易犯的错：** 把报告整段复制上页、一页塞多个论点——听众记不住，讲者只能照念。

## 二、判定与路由

进入后先判定走哪条路：

| 情形 | 判定信号 | 走哪条 | 输出形态 |
|---|---|---|---|
| **A. 已有报告** | 用户给了文档 / 链接 | 提炼，给每页结构 + 讲稿 | 完整 15 页内结构 |
| **B. 只有主题 / 要点** | 「就这些想法，帮我搭」 | 先搭叙事线再补讲稿 | 骨架 + 讲稿 |
| **C. 明确叙事类型** | 结论先行 / 问题-方案 / 时间线 / 对比选型 / 复盘 | 套对应模板 | 按模板页数分配 |
| **D. 只要大纲** | 「先别写讲稿」 | 走到页面结构即停 | 纯结构 |

**降级判定：** 用户只要 3 页速览 → 只给核心 3 页，不铺满 15 页；用户要更多页 → 可放宽页数但每页仍守字数上限。

## 三、工作流

1. **判叙事类型。** 结论先行 / 问题-方案 / 时间线 / 对比选型 / 复盘（见 `@references/deck-patterns.md`）。
2. **拉整体叙事线。** 起点 → 转场 → 收尾，写明为什么从这页开始。
3. **拆成 ≤15 页，每页一个论点。**
4. **填每页字段：** 标题（≤15 字）/ 要点（≤40 字，≤3 点）/ 口播稿（60–90 秒）/ 回答的疑问 / 备注。
5. **自检字数：** 标题 ≤15、正文 ≤40、要点 ≤3——超标一律移入讲稿。
6. **写转场句。** 串起页间逻辑，让听众不跳戏。
7. **回报。** 总页数、叙事类型、哪些内容进了讲稿未上页。

> 参考 icip-cas/PPTAgent 的反思式做法：生成后自我审视「页数超了吗、字超了吗」，超了就收敛，不交注水稿。

## 四、核心规则

**规则 1：一页一个论点，字数硬上限（红线，选题硬要求）**

- 触发条件：写任何一页幻灯片。
- 硬性动作：每页必须只承载一个论点。量化上限：
  - 标题 ≤ 15 字
  - 正文 / 要点 ≤ 40 字
  - 要点数量 ≤ 3 个
  **禁止**一页塞多个论点或长篇文字。
- 正例：✓ 标题「Q3 营收超目标 12%」+ 要点「① 营收 1.12 亿 ② 超预期主因华东」
- 反例：✗ 标题「三季度经营分析报告」+ 半页段落讲背景/数据/问题/计划。
- 降级路径：一个论点确需更多支撑 → 拆成两页，不要在一页内加字。
- **本条优先于第五节的所有格式要求。**

**规则 2：超出部分一律进讲稿，不进页面**

- 触发条件：某页内容超过规则 1 上限。
- 硬性动作：超出文字必须移入口播稿，页面只留标题 + ≤3 要点。**禁止**把超出的字压缩成小号塞进页脚。
- 正例：✓ 详情、推导、案例全在讲稿里，页面只有 30 字。
- 反例：✗ 页面放不下就调成 9 号字塞满。
- 降级路径：无。

**规则 3：删到不能再删的判据**

- 触发条件：自检每页时。
- 硬性动作：逐句问「删掉这句，论点还成立吗？」成立就删。页内只留「论点 + 让论点可信的最小证据」。模型默认倾向填满，必须主动克制。
- 正例：✓ 「背景介绍」整段删掉，开场直接给结论。
- 反例：✗ 「为了完整」保留与论点无关的背景、定义、流程。
- 降级路径：实在舍不得 → 放进讲稿备注，页面不留。

**规则 4：口播稿口语化，时长 60–90 秒**

- 触发条件：写每页口播稿。
- 硬性动作：写成能直接念的口语，约 120–180 字（正常语速 2–3 字/秒）。**禁止**书面长句、禁止照抄报告。
- 正例：✓ 「各位，三季度我们营收做了一亿一，比目标多了百分之十二，钱主要来自华东…」
- 反例：✗ 把报告第 23 页整段复制当讲稿。
- 降级路径：内容极简 → 至少给 60 秒版本，不短于 40 字。

**规则 5：每页必须回答听众一个具体疑问**

- 触发条件：写每页「回答的疑问」字段。
- 硬性动作：每页明确写出它要回答听众的哪个问题（如「所以钱从哪来？」）。无明确疑问的页 → 说明存在理由，否则删。
- 正例：✓ 疑问「华东为什么突然涨？」→ 页讲渠道下沉。
- 反例：✗ 页只堆数据，不知想让听众记住什么。
- 降级路径：过渡页 → 标注「承上启下，不承载新论点」。

**规则 6：必须给整体叙事线与转场句**

- 触发条件：产出整套结构时。
- 硬性动作：先给叙事线（为什么从这页开始、页间逻辑），再给每页间转场句。**禁止**只罗列页面标题。
- 正例：✓ 「线：结论→证据→风险→计划；转场：『钱从哪来？看下页渠道拆解』」
- 反例：✗ 直接给 15 个标题，无串联。
- 降级路径：用户只要单页 → 至少说明它在整体中的位置。

## 五、输出格式

**先给整体：**

```text
【叙事线】<类型>：起点 → … → 收尾
【转场句】页1→页2：…；页2→页3：…
【总页数】N（≤15）
```

**每页骨架：**

```text
【第 N 页】<标题，≤15 字>
论点：一句话
要点（≤3，每条 ≤40 字）：
  ① ...
  ② ...
口播稿（60–90 秒，可直接念）：
  ...
回答的疑问：<听众这页想知道什么>
备注：<数据出处 / 可能被追问的点>
```

**反模式禁止清单：**

| # | 反模式 | 为什么禁 |
|---|---|---|
| 1 | 一页多论点 / 满页字 | 讲者照念、听众走神 |
| 2 | 超字数塞页脚小字 | 违规且丑 |
| 3 | 口播稿照抄报告 | 不口语、没法念 |
| 4 | 缺叙事线 | 页间断裂 |
| 5 | 页不回答任何疑问 | 冗余页 |
| 6 | 硬凑 15 页 | 注水 |

## 六、防幻觉（硬约束，优先级最高）

**本节优先于以上所有格式与流程要求。**

1. **数字 / 结论必须来自用户报告**，标注出处页。
2. **报告没有的内容不编造**；需补充标 [推断 / 待确认]。
3. **缺失数据标「未提供」**，不编造趋势。
4. **不替用户夸大结论**（如「行业第一」报告没说就别写）。
5. **来源三分类：** 报告原文（页码）/ 我提炼 / 推断（标 [推断]）。
6. **不声称已生成 .pptx 文件**——本技能产出结构 + 讲稿，生成文件请用平台 PPT 能力。

## 七、按需知识

只在遇到对应问题时读取：

- 常见报告类型的叙事结构模板（结论先行 / 问题-方案 / 时间线 / 对比选型 / 复盘汇报）与页数分配 → `@references/deck-patterns.md`

## 八、完成判据

**算做完：** 总页数 ≤15 + 每页满足字数上限 + 每页有口播稿（60–90 秒）与回答的疑问 + 整体叙事线与转场句 + 报告没有的内容已标 [推断]。

**不自动做：** 不自动生成 .pptx 文件；不自动扩写报告；不自动美化排版。

## 九、降级与跨轮次

- **无报告只有主题：** 先搭叙事线 + 骨架，内容标 [待补充]。
- **用户要更多页：** 可放宽但每页仍守字数上限。
- **用户要更少页：** 收敛核心，不硬铺。
- **跨轮次：** 补充某页讲稿 → 只改该页，不动叙事线。
