# 常见报告类型的叙事结构模板

参考 icip-cas/PPTAgent 的反思式思路：先定叙事类型与页数骨架，再逐页填充，最后自检字数与页数。

## 一、五类叙事模板与页数分配（总页数 ≤15）

### 1. 结论先行型（周报 / 月报 / 经营分析）
适合：领导先要结果、再要理由。
- 第 1 页：核心结论（一句话 + 大数字卡）
- 第 2–4 页：支撑结论的 3 个关键证据（各一论点）
- 第 5–6 页：风险 / 异常提示
- 第 7 页：下一步计划
- 第 8 页：收尾（请领导决策点）

### 2. 问题-方案型（立项 / 提案 / 改进建议）
适合：先讲痛点，再给解法。
- 第 1 页：问题陈述（现状有多痛）
- 第 2–3 页：根因 / 影响量化
- 第 4–6 页：方案（含对比 / 步骤）
- 第 7 页：收益与成本
- 第 8 页：落地节奏
- 第 9 页：收尾（请求资源 / 排期）

### 3. 时间线型（项目进展 / 复盘前半 / 里程碑）
适合：按时间顺序讲清楚发生了什么。
- 第 1 页：时间线总览
- 第 2–5 页：分阶段关键事件（每阶段一页一论点）
- 第 6 页：当前状态
- 第 7 页：后续节点
- 第 8 页：收尾（风险与待办）

### 4. 对比选型型（技术选型 / 供应商 / A/B）
适合：多个选项摆一起比。
- 第 1 页：选型维度（评判标准）
- 第 2–4 页：各候选方案一页一论点
- 第 5 页：维度对比表 / 矩阵
- 第 6 页：推荐结论与理由
- 第 7 页：收尾（采纳建议）

### 5. 复盘汇报型（事故 / 项目总结）
适合：发生了什么、为什么、学到了什么。
- 第 1 页：结果与定级
- 第 2–3 页：时间线与事实
- 第 4–5 页：根因分析
- 第 6 页：影响与责任
- 第 7 页：改进动作（含 owner / 时间）
- 第 8 页：收尾（避免再发生的机制）

## 二、通用叙事线写法

- **起点选择：** 永远从听众最关心的一件事开场（结论 / 痛点 / 结果），不要从背景讲起。
- **转场句模板：** 「讲了 X，自然要问 Y，下页看 Z。」让每页结尾抛出一个钩子接下一页。
- **收尾：** 明确要听众做什么（决策 / 资源 / 排期），别以「谢谢大家」收尾。
  **收尾单独占一页**（页号见 §一 各模板末行），不要挤在上一页的页脚里。

## 三、每页自检清单（生成后必跑）

1. 标题 ≤ 15 字？超了删修饰词。
2. 正文 / 要点 ≤ 40 字且 ≤ 3 点？超了移入口播稿。
3. 这一页只讲一个论点？多论点拆页。
4. 口播稿 60–90 秒、口语化、非照抄？
5. 「回答的疑问」填了且具体？
6. 总页数 ≤ 15？超了合并相邻弱页。
7. 报告没有的内容是否标 [推断 / 待确认]？
8. **叙事线与转场句给了吗？**（规则 6）—— 整体叙事线（为什么从这页开始、页间怎么推）
   与每页间转场句是否齐全？**只罗列标题不算通过。**

## 四、常见翻车与纠正

| 翻车 | 表现 | 纠正 |
|---|---|---|
| 照搬报告 | 一页 500 字 | 删到论点 + 最小证据，其余进讲稿 |
| 无叙事线 | 标题罗列 | 先定类型与转场句 |
| 平均用力 | 15 页都重要 | 核心 3 页放大，次要合并 |
| 口播书面化 | 念不顺 | 改口语短句，加「各位 / 我们 / 其实」 |
| 夸大结论 | 报告没说写上去 | 标 [推断] 或删除 |
