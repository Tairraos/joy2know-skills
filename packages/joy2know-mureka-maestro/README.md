# Mureka 音乐大师（joy2know-mureka-maestro）

> 把「一段想法」炼成能直接粘进 Mureka 的双栏提示词包。

## 他解决什么问题

Mureka 的「自定义」模式是两栏输入——风格栏 + 歌词栏——写好就能出歌，写不好就白跑一次：

- 曲风词用中文写，每次生成的风格都漂；
- 中文歌词没标段落与重复位置，咬字糊、结构跑；
- 风格栏里塞了歌词、或照官方文档去找根本不存在的「时长 / 版本数」滑杆。

他站在**粘贴之前**动手：把想法炼成两栏结构化文本（风格栏英文 token 七要素 + 歌词栏中文带标签），
跑一遍结构校验，再附上粘贴前要点对的界面设置——包括那几个最容易被误触的按钮。

## 三条底线

1. **只产出提示词文本。** 不生成音频、不调用任何生成接口、不带账号与密钥；粘贴生成是用户自己在
   Mureka 里的动作。AI 音乐有随机性——他提高命中率，不承诺效果。
2. **中文歌词三件套不许省。** 语言声明句、段落标签、重复位置显式写——这是中文歌「咬字糊、跑结构」的解药。
3. **结构校验由脚本算。** 校验器在 `skills/joy2know-mureka-musician/scripts/mureka_check.mjs`，
   FAIL 修到零才交付，WARN 逐条给处理说明；觉得判定不对，先回技能规则核对，不临场发明第三种口径。

## 擅长的体裁

**爵士、蓝调、民谣**——三者各自有完整的配方（BPM 区间、乐器盘、结构、句式），也擅长两两融合
（民谣爵士、乡村蓝调、蓝调爵士——Mureka 官方明确鼓励风格融合）。默认落点是治愈系民谣：
接受面最广，不满意时改一个曲风词就能换壳。流行、City Pop 等其他曲风按同一套七要素适配。

## 包内容

```
joy2know-mureka-maestro/
├── .codebuddy-plugin/plugin.json            核心配置
├── agents/joy2know-mureka-maestro.md        角色定义（系统提示词）
├── avatars/expert.png                       头像 512×512（由构建注入）
├── skills/joy2know-mureka-musician/         内置技能（方法论与校验器，由构建注入）
│   ├── SKILL.md                             双栏四层 / 路由 / 七条核心规则 / 交付格式
│   ├── references/
│   │   ├── mureka-controls.md               实测控件全表 · 参考歌曲与性别冲突 · 交付前必做
│   │   ├── style-tokens.md                  风格栏七要素 · token 正反例 · 融合配方
│   │   ├── genre-cookbook.md                爵士 / 蓝调 / 民谣完整配方
│   │   └── lyrics-craft.md                  治愈文风内核 · 中文补断句 · 三套预设
│   └── scripts/
│       └── mureka_check.mjs                 结构校验器（21 项自检内置）
└── README.md
```

**方法论主体在 `skills/joy2know-mureka-musician/`，与独立上架的技能包同源。** 角色定义只规定流程与验收标准，
不重复技能内容——避免同一份规则两处维护导致版本漂移。

> **形态说明**：上面的目录树是**构建后所得包的形态**。仓库里的**源包**只有
> `.codebuddy-plugin/plugin.json`、`agents/joy2know-mureka-maestro.md`、`skills.json` 与 `README.md` ——
> `avatars/` 由构建从仓库根 `avatars/joy2know-mureka-maestro.png` 注入；`skills/` 由构建按 `skills.json`
> 声明的名单，从 `packages/<技能名>/` 复制**唯一真源**（本包内不存副本）。

## 怎么用

装上之后直接提问即可，不需要点名模式。

| 你说 | 他做 |
|---|---|
| 给我写一首能粘进 Mureka 的歌 | 五问走默认值 → 双栏提示词包 + 界面设置 |
| 写一首深夜厨房主题的蓝调民谣 | 民谣蓝调融合配方 → AAB 句式歌词 → 脚本校验 → 交付 |
| 这两栏提示词帮我检查一下再粘 | 跑结构校验器，FAIL 修零、WARN 逐条说明 |
| 我什么都还没想好 | 全默认治愈民谣直接产出，替你定的项逐条写在「假设与待替换」 |
