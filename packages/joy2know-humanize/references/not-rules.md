# 不可改清单

这张表和规则表一样是硬约束。列在这里的特征**看着像 AI 腔，实测站不住**，不能据此改文字。它们在公共讨论里流通得很广，所以每隔一段时间就会有人「顺手」按它们改一遍——那正是这篇文章要被退回的原因。

区分原则：**规则的依据是触发标记可定位，不是频率高低。**

| 特征 | 证据 | 为什么不改 |
|---|---|---|
| 句长、段长的参差度 | 已实测（公开对照研究） | 实测两侧无差异。为了「制造节奏」调句长或拆段落，等于按一个不存在的特征改稿。 |
| 单字虚词（就／很／了）偏少 | 已实测（公开对照研究） | 方向是「人类更多」而不是「生成文本更多」。补虚词无法验收，还会把正式文章改成口语。 |
| 反复写全称、少用代词 | 已实测（公开对照研究） | 人类比生成文本更常重复同一名词。反过来说「补代词」也没有依据。 |
| 被动句、「被认为／被视为」 | 已实测（公开对照研究） | 绝对量低于收录门槛，两侧都极少。抽象被动不是中文机器腔的判别特征。 |
| 名词化结构本身（完成了对……的……） | 反向（人类侧更高，只能禁止反向改） | 公开对照数据是反向的（人类侧更多），而通行规则集里仍收了这一条——本版不收。只在「原文已有具体数据」时禁止用概括词盖掉（R11）。 |
| 正文里的「首先……其次……最后」 | 已实测（公开对照研究） | 与人类写作无差别。只有小标题编号（R05）才处理。 |
| 句内同构排比（提升效率，降低成本，优化体验） | 已实测（公开对照研究） | 人类用得不比生成文本少。只处理相邻句之间的同款（R09）。 |
| 问句、设问、问句小标题 | 反向（人类侧更高，只能禁止反向改） | 正文设问人类远多于生成文本。按「删设问」改会把文章改得更不像人写。 |
| 比喻本身、比喻独立成段 | 反向（人类侧更高，只能禁止反向改） | 人类用比喻的频率是生成文本的数倍。只有「理想化职业人格」这一种喻体（R10）才处理。 |
| 具体的人当喻体（像一个老师傅） | 已实测（公开对照研究） | 人类就这么写，属说明性比喻，不是抒情。 |
| 抽象名词配具体动词（时间替他保管了细节） | 已实测（公开对照研究） | 两侧都几乎不写，测不出差异。 |
| 长句本身 | 已实测（公开对照研究） | 现代汉语书面语的正常写法，不是译文句式的证据。 |

## 还有一层：不因为「读着不像人写的」就改

主观上觉得某句生硬、不像中文，不构成改动理由。只有能在规则表里指出触发标记的，才允许动。指不出对应规则号的改动一律撤销。

## 豁免区

| 区块 | 说明 |
|---|---|
| 围栏代码块（``` / ~~~） | 代码不属于改写范围 |
| 行内代码 `…` | 同上 |
| 文件开头的 YAML frontmatter | 元数据不是正文 |
| 引用块（> 开头） | 引用他人原文不得改动 |
| 表格行（| … |） | 表格是结构化内容，改了会散架 |
| 列表行（- ／ * ／ 1. ） | 列表本身是结构；只有引出列表的那句话（R03）才处理 |
| 图片与链接行 | 不是正文 |
| 整段是引语的段落 | 对话体本来就是自然表达，不要统一改写 |
| 非中文为主的段落 | 本技能只做中文论述文 |
