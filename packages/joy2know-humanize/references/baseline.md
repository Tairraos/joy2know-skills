# 量级口径、来源与局限

这份文档回答三个问题：规则表里的「强／中／弱／反向」是怎么定的；这些判断的依据是什么；哪些地方本版没做好。

---

## 一、量级口径

规则表用六级标签描述「这条规则值不值得改」。阈值是频率比 *R* = 生成侧频率 ÷ 人类侧频率：

| 标签 | 判据 | 怎么用 |
|---|---|---|
| 强 | *R* ≥ 3.0 | 有条件就该改 |
| 中 | 2.0 ≤ *R* < 3.0 | 应该改 |
| 弱 | 1.25 ≤ *R* < 2.0 | 条件采纳，看整篇密度 |
| 不稳定 | *R* 达标但组间或跨模型差异过大 | 降为「视情况」，不逐处判死 |
| 反向 | *R* < 0.8，人类侧更高 | **只能用来禁止往反方向改**，不能当删除理由 |
| 本版新增 | 无对照数据 | 可选，用户可一句话关掉 |

频率之外还有两个必要条件，缺一不可：

**可定位。** 特征必须能落到具体句段与词形上。像「比喻是否贴切」「并列案例是不是在凑数」这类依赖语义理解的判断，写不成本事可执行的算子，一律排除——写进规则只会诱导按主观语感乱改。

**可改写。** 特征成立不等于能拿来改。「材料密度低」这一项方向明确，但据此「补充数据」会违反信息守恒，所以只保留它可执行的那一半：原文已有具体数据时，不许用概括词盖掉（R11）。

**分母要跟被测单位匹配。** 结构类指标（比如「问句小标题」）的分母必须是同类元素的总数，不是字数——生成文本的小标题数量本身就是人类的几倍，用字数当分母会把差异放大一个量级。这条经验是本版设计 R05（序数词小标题）与 R09（相邻句同构）时的硬约束。

## 二、来源

本版规则表的频率依据来自一份公开的对照研究（MIT 许可）：629 篇文章、282.7 万汉字、9.55 万句、4.57 万段，其中 300 篇由五个主流模型在受控条件下生成，329 篇为人类作者文本，逐项检验 26 个在公共讨论中被认作「AI 文风」的候选特征。

那份研究最值钱的产出不是它收了哪些特征，而是它**否掉了哪些**：26 项里有 15 项不具区分力，其中数项方向与流行认知相反——人类使用比喻的频率是生成文本的 2.4 倍，正文设问是 17 倍，句内同构排比也更高。本版把这些结论整体收进 @references/not-rules.md，当作硬约束。

**语料未被本版独立复现。** 库内没有那批语料，也没有重跑统计。规则表里的量级标签是对那份公开结论的转写与再分级，不是本版自测的结果。要复算，得自己备一份对齐了话题与文体的人类语料与生成语料。

## 三、本版与那份公开研究的四点不同

写在前面：结构与方法借鉴了它，分歧也明说。

**1. 规则只存一份。** 那份研究把正则抄在每个脚本里，文档写一套、算子写一套。它自己在方法局限里承认这是全链最薄弱的一环，并记录了六次因为「算子与规则名覆盖范围错开」导致的测量失误——其中两次方向是反的，据此改写会让文本更偏离人类写作。本版把规则收进 `scripts/rules.py` 一个真源，文档由它生成，并给每条规则自带正反例：正例必须被命中、反例必须不被命中。规则写错，`selftest.py` 立刻红，改稿前就拦下。

**2. 机械与语义分治。** 那份研究把全部改写交给模型。本版把不需要读懂句意就能改对的条目（翻案腔、序数词小标题、起手式、「当……时」、复述句）交给脚本：零 token、零漂移、可回滚。剩下的留给人——脚本替不了的判断，硬做只会把文章改坏。

**3. 验收从自觉变成门禁。** 那份研究的验收是一张自查清单，靠执行者逐条确认——而同一段文字既是被改的对象又是自查的依据，写着写着就会顺手润色。本版把这四类约束做成可执行的检查：硬守恒、强度守恒、结构守恒、越界改动。其中**越界改动**是最难自查的那条，本版按句子而不是按行判：同一行里常有两三句话，按行判的话，顺手把没命中的那句润色一遍也能过。

**4. 给每条规则标证据等级。** 那份研究在局限一节承认，译文句式的筛选只依据生成侧绝对频率、没有人类侧对照。本版把这种可靠性差异显式标出来（强／中／弱／不稳定／反向／本版新增），并规定「反向」与「本版新增」两类不能被当作硬性要求。

顺带指出那两份文档之间的一处不一致：名词化结构（「完成了对……的」「实现了……的提升」）在那份研究的检验表里是 **R = 0.52**，人类侧更高，属于「未通过检验」的 15 项之一；但它的规则集里仍收了这一条。本版把它移进不可改清单，只保留「原文已有具体数据时不许用概括词盖掉」这一半。

## 四、局限

**规则表未经本版独立复现。** 量级标签转写自公开结论。若你的语料与那批研究的体裁不一致，结论可能不成立。

**语义层的机器腔调测不到。** 「段落是不是在凑字数」「这个论断有没有依据」，这类问题的判断超出正则算子的能力，本版一律不碰。如果机器腔调的主要成分位于语义层，这套方法在原理上够不着。

**模型在向人类文风收敛。** 所有频率数值都是特定时点的观测，会过期。参考点是：破折号这一项，同一个模型在不到一年里从「近乎每句一次」降到每侧千字 0.11。规则表里的阈值应视为待刷新的值。

**R13 是经验性规则。** 「时代背景起手」为本版新增，没有对照数据，属于观察到但未验证的那一类。它能被一句「只改有据可查的」整体关掉。

**正反例覆盖面有限。** 每条规则的正反例只有几条，够拦住明显的算子错误，拦不住所有误报。所以工作流里保留 `--audit` 抽样——**先看命中实例，再采信算子**，这一步不能省。
