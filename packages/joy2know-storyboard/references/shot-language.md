# 景别与运镜术语表（中英对照）

## 一、景别 Shot Size

| 中文 | 英文 | 含义 | 何时用 |
|---|---|---|---|
| 大远景 | extreme long shot / wide shot | 人在环境中极小，强调空间 | 交代世界观、孤独感 |
| 远景 | long shot | 人物全身入画，环境仍主导 | 展示场景规模 |
| 全景 | full shot | 人物从头到脚占满画面 | 动作、站位 |
| 中景 | medium shot | 人物腰部以上 | 对话、互动（最常用） |
| 中近景 | medium close-up | 人物胸部以上 | 情绪+动作兼顾 |
| 近景 | close-up | 人物肩部以上 | 表情、细节 |
| 特写 | extreme close-up | 局部（眼、手、物件） | 强调关键细节 |

## 二、运镜 Camera Movement

| 中文 | 英文 | 含义 | 何时用 |
|---|---|---|---|
| 推 | push-in / dolly in | 镜头向主体靠近，主体变大 | 聚焦、情绪逼近 |
| 拉 | pull-out / dolly out | 镜头远离主体 | 揭示环境、抽离 |
| 摇 | pan | 镜头水平转动 | 横扫场景 |
| 移 / 跟 | tracking / follow | 镜头平行移动跟随主体 | 行走、追逐 |
| 升降 | crane / jib | 镜头上下移动 | 宏大、俯仰视角 |
| 环绕 | orbit / arc | 绕主体旋转 | 展示、仪式感 |
| 手持 | handheld | 轻微抖动的主观视点 | 紧张、纪实 |
| 固定 | static / locked-off | 镜头不动 | 对话、静默 |
| 变焦 | zoom | 焦距变化（非位移） | 快速聚焦，慎用易显廉价 |
| 俯拍 | high angle | 从上往下 | 压迫、渺小 |
| 仰拍 | low angle | 从下往上 | 力量、崇高 |
| 俯仰摇 | tilt | 镜头上下摆动（非位移） | 展示高大物体 |
| 甩镜 | whip pan | 极快水平摇，画面拉丝 | 转场、时间跳跃 |
| 变焦冲击 | dolly zoom / vertigo | 位移与变焦反向，空间扭曲 | 震惊、梦境 |
| 变焦跟焦 | rack focus | 焦点在前后景间切换 | 转移注意力 |

## 三、组合写法示例

提示词里把「景别 + 运镜」成对写，模型执行最稳：

- `Shot size: close-up; Camera: slow push-in` → 近景缓慢推近
- `Shot size: medium shot; Camera: static` → 中景固定
- `Shot size: extreme long shot; Camera: slow pull-out` → 大远景缓慢拉远
- `Shot size: medium close-up; Camera: handheld follow` → 中近景手持跟拍

## 四、反模式

| 反模式 | 问题 |
|---|---|
| 写「镜头很有张力地靠近」 | 模型读不懂「张力」，应写 `push-in` |
| 景别与运镜矛盾（特写 + 环绕） | 信息冲突，生成摇摆 |
| 每镜都写「电影感运镜」 | 空泛，应落到具体术语 |
| 用中文口语「往前怼」 | 不标准，写 `push-in` |

## 五、选用建议（按创作意图）

- 想让观众「代入角色」：中近景 + 手持跟拍。
- 想「交代世界」：大远景 + 缓慢拉远。
- 想「聚焦情绪」：近景 + 缓慢推近（push-in）。
- 想「制造冲击」：先用固定中景，切变焦冲击（dolly zoom）。
- 跨镜头保持角色一致：景别可随叙事变化，但**锚点描述（服装/外观短语）不动**，见角色档案技能。

> 一条提示词里景别与运镜各写一对即可，写多反而互相干扰。
