# Suno / Mureka 字段与控件对照（专辑级用）

## 一、两套字段的根本差别（先分清，混写必错）

| | **Suno** | **Mureka** |
|---|---|---|
| 结构 | 三段独立字段：**标题 + Style + Lyrics** | 双栏：**风格栏 + 歌词栏** |
| 风格字段 | `Style (Suno Optimized)`，一行，九字段 | 「风格栏」，≤1000 字，英文 token |
| 歌词字段 | `Lyrics (Suno Structure)`，≤可容纳段落标签 | 「歌词栏」，**≤5000 字** |
| 语言锁 | 写进 **Style 第一字段**，歌词栏再加 `[Language:]` / `[Accent:]` | 靠**歌词栏最前的语言声明句**，风格栏**不写**语言锁 |
| 人声一致性 | Style Persona / Voices（平台功能） | +自定义歌手（平台功能） |
| 会改写你文本的开关 | **Variety**（归 0） | 风格栏的**「增强」**（别点） |

**Mureka 风格栏里出现 `Standard Mandarin Enunciation` 或 `Language:` 这类 Suno 式语言锁 → 是错。**
Mureka 的人声语言靠歌词栏声明句体现，风格栏只管曲风与人声质感。

## 二、平台粘帖提示词与配置参数要点（第 2 章按平台写哪一段）

### 2.1 粘帖提示词（每次交付都要附）

| 平台 | 提示词要写清什么 |
|---|---|
| **Suno** | ① 标题（中文或 `Instrumental` 标注）；② Style 九字段，**语言/口音在第一字段**，写完附一行中文翻译；③ Lyrics 段落标签 + 正文（器乐包方括号外留空） |
| **Mureka** | ① 模式 =「自定义」；② 风格栏英文 token，**七要素齐、BPM 必给**，写完附一行中文翻译；③ 歌词栏 = 语言声明句 + 段落标签 + 中文歌词（纯音乐包只留方括号编曲标签） |

### 2.2 配置参数要点（**必做类，交付块里逐条对应**）

**Suno**

1. **把 Variety 归 0** —— 官方明确 Variety 会**改写你写的 Style 文本**，而语言锁、BPM、`Seamless loop` 全写在 Style 里。
2. 器乐包：Style 前两字段合成 `Instrumental, No vocals`，**不写** `[Language:]` / `[Accent:]`。
3. 循环包：`Seamless loop` + `No fade in` + `No fade out`，BPM 写死单个数字。
4. 多首同人声：用 Style Persona / Voices 锁，**不靠提示词**。

**Mureka**

1. 模式：自定义。
2. **⚠️ 不要打开「纯音乐」开关** —— 实测打开后**歌词栏被锁死、无法粘贴**，方括号编曲标签贴不进去，
   于是「靠歌词栏控制音乐流向」这条路直接断掉。纯音乐靠**风格栏首句 `No vocals` + 全篇无人声词**压制，
   音乐流向用**歌词栏的方括号编曲标签**写（前提是开关不开）。
3. 人声性别：与风格栏的 `female vocal` / `male vocal` 保持一致；
   **若同时用参考歌曲 → 二者只留其一**（官方 FAQ：同时给时优先采用音频参考，性别设置可能不生效）。
4. **⚠️ 别点风格栏的「增强」** —— 它会改写你写好的英文 token。
5. **⚠️ 本面板没有时长 / 版本数 / 人声参数滑杆，别去找**（实测纠偏：一次生成出 2 个变体、时长由平台决定）。
6. 多首同人声：用 **+自定义歌手**，**不靠提示词**。

## 三、纯音乐专辑的字段写法（两平台通用逻辑，字段名不同）

| 要素 | Suno 写法 | Mureka 写法 |
|---|---|---|
| 器乐声明 | Style 前两位 `Instrumental, No vocals` | 风格栏**首句** `No vocals` |
| 语言锁 | **不写** `[Language:]` / `[Accent:]` | 不写语言声明句 |
| 歌词栏 | 方括号外留空，圆括号指令只留非人声那类 | **方括号外一个字不留** |
| 段落标签 | `[Intro] → [Loop A] → [Loop B] → [Loop A2] → [Loop C] → [End]` | 同左（英文标签） |
| 编曲流向 | 写在标签的圆括号/破折号后 | 写在标签的破折号后 |
| 人声词禁令 | `vocal / singer / humming / choir / ooh` 全禁 | 同左 |
| 开关 | 无此开关 | **纯音乐开关保持关** |

**为什么段落标签禁用 `Verse / Chorus / Bridge`**：这三个词本身携带「有人唱」的结构语义，
模型会据此补人声。纯音乐要的是 `Intro / Loop A / Loop B / Loop A2 / Loop C / End` 这一组**器乐段名**。

**音乐流向靠什么写**：靠方括号里**具体的编曲动作**，而不是靠段名。例如：

```text
[Intro – 独奏钢琴，单音，留白 8 小节]
[Loop A – 加入大提琴长音，力度渐强，无鼓]
[Loop B – 刷鼓进，加入低八度贝斯，钢琴转和弦伴奏]
[Loop A2 – 回到 Loop A 织体，去掉鼓，钢琴上行]
[Loop C – 全奏，弦乐叠高八度，铜管一记点缀后收]
[End – 回到开头的和弦与织体，干净切断，无淡出]
```

## 四、无缝成环的四条硬约束（两平台同）

1. **禁淡出** —— 风格栏写 `no fade in, no fade out`；段落标签里不许出现 `fade out` / `fading`。
2. **BPM 写死单个数字** —— 不锁 BPM，循环点会落在小节中间；写成区间（`BPM 70 to 80`）同样不行。
3. **首尾同源** —— 结尾段写「回到开头的和弦与织体、干净切断」，不是渐弱收尾。
4. **不承诺直出无缝** —— 生成物是**素材**；真正的无缝靠用户裁到整数小节 + 标 loop point + 接缝交叉淡化，
   那一步在用户自己的编辑器里做，本技能只给步骤清单。

**注意**：`no fade in` / `no fade out` 这两个词**包含** `fade in` / `fade out` 子串** ——
校验器必须先剥掉否定声明词再查淡出，否则声明本身会被误报（`album_check.py` 与单曲校验器都这么做）。

## 五、封面提示词怎么写（第 8 章每首都附）

封面图由用户在绘图工具出，本技能只给**提示词文本**。每首必须包含四件事：

| 要素 | 写法 | 反例 |
|---|---|---|
| **点名曲名文字** | `封面文字：<曲名>`（逐字一致，不改字） | 只写「一张忧郁的封面」 |
| 字体 | `纤细手写体` | 不写字体 → 用户自己加字 |
| **留白位置** | `右侧三分之一留白，竖排` / `上方留白，横排` | 不写位置 → 文字压在主体上 |
| 画面 | 与该曲的意象、调式色彩一致 | 与该曲无关的通用图 |

**专辑级的一条纪律**：整张专辑的封面提示词要共用一组**视觉母题**（同色调体系、同构图逻辑），
只有意象与留白侧随曲目变化 —— 否则做出来是 N 张不相干的图，不是一套。

## 六、平台能力边界（不提套餐、档位与计费）

| 能力 | 在哪 | 提示词怎么配合 |
|---|---|---|
| Suno Style Persona / Voices | Suno 平台 | 多首同人声唯一可靠手段；提示词照写，但要说明「一致靠平台功能」 |
| Suno Studio 改词保旋律 | Suno 平台 | 已生成的歌改词保留旋律与人声；本技能的歌词栏可直接用于它 |
| Mureka Remix（哼唱旋律） | `+Remix` | 有旋律参考时风格栏**不要**描述旋律，只写目标风格 |
| Mureka 自定义歌手 | `+自定义歌手` | 同上：人声一致靠它，不靠提示词 |
| Mureka Studio 改词保旋律 | 工作室版块 | 同上；账号是否可用以界面为准 |
| 下载 / 导出 | 生成结果页 | 能力与账号状态相关，**不提档位**；用户问就让他看界面 |
