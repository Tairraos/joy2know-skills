# 歌词设计师（joy2know-lyricist）

> 把「一段感觉」炼成**能唱的词** —— 按体裁选对押韵方案，先定钩子再写副歌，逐段检查结构。

## 他解决什么问题

写歌词最容易出的不是「不好」，是**不像词**：

- 满篇霓虹与破碎，换成任何别的歌也成立 —— 等于什么都没说；
- 两段主歌是同一场景的近义改写，读者听第二遍才发现是AI 写的；
- 副歌「好听但记不住」—— 因为没有钩子句，只有一整段漂亮的词；
- 押上了韵就把语法掰了、生造了词，为落韵牺牲语义；
- 给民谣套密集尾韵像儿歌，给说唱写抒情散押唱不出 flow —— **体裁的押韵约定没有普适默认**。

他站在**词成形之前**动手：一轮问答收齐七项信息 → 给五个框景角度让用户挑 →
锁死框景写主歌 → 主歌二换场景 → **给三个候选钩子** → 才写副歌。
每一步都停下来让用户确认。

## 三条底线

1. **只产出文本。** 歌词 + 段落标签 + 风格栏建议，到此为止。不生成音频、
   不调用任何生成接口、不带账号与密钥；粘贴生成是用户自己在音乐平台里的动作。
   AI 音乐有随机性 —— 他提高命中率，不承诺效果。
2. **体裁决定押韵方案。** 十七种体裁各有各的约定，动笔前必查那张表
   （`references/genres.md`）。**不拿记忆里的流行歌习惯去写民谣或说唱。**
3. **六条纪律由脚本算。** 校验器在 `skills/joy2know-lyric-design/scripts/lyric_check.py`，
   FAIL 修到零才交付，WARN 逐条给处理说明。

⚠️ **但脚本查不了三条，必须人读**：画面是否成立、主歌二是否真换场景、语义是否被韵脚破坏。
**六条全过不等于词写得好** —— 他会这么告诉你，不给虚假的安全感。

## 擅长什么

**17 种体裁各有方案**：流行 / 民谣 / 摇滚 / 朋克 / 金属 / 说唱 / R&B / 放克 /
电子 / 氛围 Lo-Fi / 爵士 / 布鲁斯 / 乡村 / Reggae / Afrobeats / 福音 / 古风国风。
**中文为主**：四五六七言句式与顿点、十三辙与开口韵、国风意象库、通感修辞。

**陈词滥调清理**是强项：禁用清单（霓虹 / 破碎 / 永恒 / 今晚当韵脚 / 万能句式）
**必须配一条必需物清单** —— 只禁不逼，模型会在剩下的空间里继续偷懒。

## 用法

直接说「帮我写首歌词」，或者把你那一句感觉整段丢过来。
改词就说「打磨这版词，但别整首重写」—— 他只改该改的那部分，附「改前 → 改后」对照。

## 边界

不做旋律与和声、不做封面与 MV、不剪音频、不承诺效果、
**不提供版权查重 / 作品登记 / 歌词投稿**（那些是平台与版权机构的事）。
提到某位创作者只提取可公开描述的音乐特征，不写「仿某某的歌词」。
