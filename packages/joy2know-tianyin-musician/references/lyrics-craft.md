# 天音场景歌词写法（预设引用）

> **定位声明**：歌词正文的完整规则——体裁押韵方案、钩子四型、陈词滥调禁用清单、分阶段出稿流程——
> **一律以 `joy2know-lyric-design` 技能为准**。本文件只是它在「网易天音歌词栏」这个场景下的
> **预设引用**：只规定粘贴进天音歌词框时的形态约定，不另立一套歌词规则。
> 用户要「先把词写好」时，走 `joy2know-lyric-design` 的出稿流程，成稿回来后按本文件贴进歌词栏。

## 一、段落标记约定

天音歌词栏是自由文本，**不强制标签语法**，但标记能大幅减少结构误判。约定：

- 段名用方括号包裹，写在段首独立一行：`[前奏]` `[主歌]` `[副歌]` `[桥段]` `[尾奏]`
  （英文 `[Intro]` `[Verse]` `[Chorus]` `[Bridge]` `[Outro]` 亦可，**全篇统一用一种**）。
- 可在标记里带一句编曲提示：`[主歌 – 半念半唱，贴近话筒]` `[副歌 – 开阔，层叠人声]`。
- **段名禁用量**：纯音乐路线歌词栏留空，本节约不适用。

## 二、语言声明（中文歌必带）

歌词栏**最前面**写一句：

```
全部使用简体中文。
```

理由：天音按输入自动判断语言，一句声明能压住「掺英文词、拼音混进来」的漂移。
整首英文歌时不写这句，改为 `Sing in English.`（或按用户要求的语言声明）。

## 三、重复位置显式写

第二遍副歌**不许让模型猜**：

- 完全重复：`[副歌 – 重复上面的副歌]`
- 变句重复：`[副歌 – 重复上面的副歌，末句改成「比相爱更勇敢」]`

## 四、行长与段长

- **每段 4–8 行**；行不宜长（中文一行≈7–12 字），靠标点自然断句——行太长是吞字主因。
- 全曲结构默认 `前奏 + 主歌 + 副歌 + 桥段 + 副歌 + 尾奏`；用户要精简可砍到 `前奏 + 主歌 + 副歌 + 尾奏`，
  **语言声明与重复位置标注不砍**。

## 五、与「副歌前置」开关的配合

- 开「副歌前置」时，平台会自动识别副歌位置并前置——**副歌必须自己立得住**
  （一句 3–9 字的钩子），否则等于把弱点提前。钩子写法以 `joy2know-lyric-design` 为准。
- 关「副歌前置」时按正常叙事顺序写，主歌负责铺垫。

## 六、文风内核（默认配方）

天音场景默认沿用治愈系配方（完整版在 `joy2know-lyric-design`，此处只列要点）：

- 主歌用**具体写实动词**铺生活细节（「锅铲刮过锅底的声响」）；
- 意象用「具象名词 + 抽象动词」重组（「思念生锈」）；
- 副歌用**矛盾修辞**造张力（「拥挤的孤独」）；
- 语气词一句一个；**主歌闭口韵、副歌开口韵**。

用户指定体裁（国风/说唱/摇滚……）时，音乐外壳与体裁句式全换，**画面感与具体性保留**——
「换风格」不等于「可以写空泛」。

## 七、不编造

- 只用用户提供的信息；涉实名、品牌、具体事件的一律不编，需要锚点就写 `[待替换：……]` 占位并列清单。
- 不编造参考歌手的具体作品；提参考只写风格特征。

## 八、粘贴前自检（歌词栏）

- [ ] 语言声明句在最前（中文歌）
- [ ] 段名标记全篇统一、写在段首
- [ ] 第二遍副歌显式标注重复
- [ ] 每段 4–8 行、行不长
- [ ] 副歌有一句能独立站住的钩子（开副歌前置时尤其要查）
- [ ] 纯音乐路线：歌词栏**留空**
