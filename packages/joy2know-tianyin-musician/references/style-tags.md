# 18 个风格标签与风格描述写法

> 标签名单来自 2026-10-18 登录态实测（高级模式风格描述栏上方，**单选、横向滚动**）。
> 平台会更新标签 —— **以用户当前界面为准**；用户界面出现新标签时，按下面的「四要素」方法现场适配，不硬套本表。

## 一、风格描述怎么写：四要素一句式（官方范式）

官方 placeholder 原文就是范式：

> 「和我说说你想要的风格吧，比如：**都市 R&B，用吉他伴奏和清澈男声演唱，要那种浪漫又心动的 Vibe**。……」

拆开就是四要素：

| 要素 | 写什么 | 例子 |
|---|---|---|
| **① 曲风** | 1–2 个流派（可点上方标签当代谢起点） | 都市 R&B / 民谣 / 国风 |
| **② 乐器伴奏** | 主奏乐器 + 织体轻重 | 用吉他伴奏 / 木吉他指弹 / 钢琴轻铺 |
| **③ 人声** | 性别 + 唱法 + 气质（纯音乐时写「不要人声」） | 清澈男声演唱 / 温暖女声轻轻唱 |
| **④ 情绪氛围（Vibe）** | 一句有画面感的气氛描述 | 浪漫又心动 / 像夏夜阳台聊天一样松弛 |

**可加的第五句**：速度与规模——「中速」「三分钟上下」（自然语言即可，天音没有 BPM 输入框）。

**节奏建议**：四要素一句式串起来，100–300 字为宜（上限 1000，写够细节即可，不必堆满）。
**标签与描述的分工**：点标签 = 快捷起点；描述栏 = 主输入，四要素必须自己在描述里写全，
**不能只点一个标签就交差**（只点标签时其余三要素全靠模型脑补）。

## 二、18 个标签逐个画像

| 标签 | 画像 | 描述里补什么 | 避什么 |
|---|---|---|---|
| **国风** | 古韵意象、传统调式色彩 | 民族乐器（笛/箫/古筝）+ 婉转唱法 | 现代电子鼓过重 |
| **民谣** | 木吉他叙事、松弛人声 | 指弹/弹唱、生活化场景 | 炫技编曲 |
| **抒情流行** | 大线条抒情、副歌易上口 | 钢琴/弦乐铺底、情绪推进 |  verse 太碎 |
| **R&B** | 都市节奏、转音撩人 | 电钢/贝斯 Groove、深夜场景 | 民谣木吉他味 |
| **怀旧港风** | 八十年代港式情歌 | 合成器 + 电吉他、粤语咬字感 | 现代 EDM 音色 |
| **爵士** | 即兴、摇摆、松弛 | 钢琴三重奏感、萨克斯点缀 | 四拍子重电子鼓 |
| **摇滚** | 吉他与真鼓的推力 | 失真吉他、直给情绪 | 过度柔情 |
| **hip-hop** | 说唱 flow、强节奏 | 808 感贝斯、trap 或 boom bap | 旋律线太满 |
| **孟菲斯说唱** | 阴暗低沉的说唱底色 | 压嗓、慢速 flow、夜色调 | 明亮偶像感 |
| **电子 / DJ** | 合成器与律动 | build-up/drop 结构、舞池场景 | 人声太抢 |
| **蒸汽波** | 复古未来、慢速浪漫 | 萨克斯采样感、大量混响 | 现代流行鼓组 |
| **kpop / J-pop** | 偶像团体明亮感 | 整齐和声、青春场景 | 沧桑烟嗓 |
| **欢乐儿歌** | 童真欢快 | 简单旋律、游戏/节日场景 | 成人抒情 |
| **氛围雷击顿** | 氛围感 + 雷击顿律动 | 慢速 dembow、空间感 | 传统流行结构 |
| **黑人福音** | 大合唱、光辉感 | 教堂场景、和声堆叠 | 独白式清唱 |
| **网感流行** | 短视频热歌体质 | 15 秒内进 hook、口语化 | 冗长前奏 |
| **现代流行** | 当下主流流行 | 按情绪选配器，从简 | 元素堆太满 |
| **网感流行×怀旧港风**（可融合） | 两条都命中时 | 选一个为主、另一个作点缀 | 两套骨架硬拼 |

> **融合纪律**：一次**以 1–2 个标签气质为主**；风格描述里流派词不超过三个基色，多了模型只能自行发挥。

## 三、正反例

**正例（民谣，四要素齐）**

```
民谣，木吉他指弹伴奏，温暖女声轻轻唱，像夏夜阳台聊天一样松弛，三分钟上下。
```

**正例（国风 + 虚拟歌手祝宁）**

```
国风流行，笛子与古筝点缀、吉他轻铺，婉转女声唱江南旧事，要那种烟雨朦胧的Vibe，中速。
```

**正例（纯音乐，走简易模式开关）**

```
深夜书房专注背景音乐，只有钢琴和轻雨声，不要人声，循环着放也不违和。
```

**反例**

| 反例 | 问题 |
|---|---|
| `流行，伤感，钢琴` | 无叙事的关键词罗列——不是官方范式 |
| `R&B` | 只点/只写一个曲风名，其余三要素全靠脑补 |
| `国风 + 摇滚 + 电子 + 爵士` | 基色超过三个，结果四不像 |
| `先 R&B 后民谣` | 一句之内换骨架，模型只能二选一或混搭失控 |
| 「错过出口，却遇见更好的风景」 | 卡片营销语，不是给模型的指令 |

## 四、与控件的一致性（规则 3 的落地）

风格描述里的人声（「清澈男声」）必须与**人声性别按钮**、**虚拟歌手的声线**一致；
纯音乐路线的人声位写「不要人声」并留空歌词栏。三者关系的完整判据在 `SKILL.md` 规则 3，
歌手名单在 `singer-cookbook.md`。
