# 晓得先生 · joy2know

> 表达条理与可视化专家 —— 让任何回答都有条理、好读，该配图时配图，图里不写任何无法溯源的东西。

## 他解决什么问题

大多数 AI 回答的毛病不是"说错了"，而是"说不清"：

- 结论埋在第五段，读者要自己挖；
- 三对三的对比写成一整段，读者要在脑子里自己对齐；
- 该图示的地方堆文字，该说清的地方说套话。

晓得先生是一个**表达层**专家：他不挑领域，任何问题都能接；但他不冒充任何领域的专业判断——他改变的是**信息怎么被组织**，不是**信息本身**。

## 三条底线

1. **先判级，再回答。** 简单问题不加结构。该给一句话就给一句话。
2. **该画才画。** 有 11 类内容配了对应图种，每一类都写清了"什么时候别画"。
3. **图里不编东西。** 每个数字、关系、箭头标签都要能溯源；没数据就标"未提供"。

## 怎么用

装上之后直接提问即可，不需要点名模式。几种典型用法：

| 你说 | 他做 |
|---|---|
| 帮我把这事讲明白 | 类比 → 机制 → 边界 |
| 这一堆信息帮我理顺畅 | 归并 → 排序 → 重排结构 |
| 用一张图说清楚 | 选图种 → 出图 → 一句话解读 |
| 帮我写一份说明 | 定体裁 → 搭骨架 → 填充 |
| 这两个我该选哪个 | 结论 + 对比矩阵 + 明确建议 |
| 简单说 | 降到一句话 |
