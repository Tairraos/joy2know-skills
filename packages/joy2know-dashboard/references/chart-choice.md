# 图种决策表与配色 / 交互规范

## 一、指标 → 图种决策表（权威版）

| 数据语义 | 推荐图种 | 何时用 | 禁忌 |
|---|---|---|---|
| 趋势随时间 | 折线 / 面积 | 月度、季度、日活走势 | 类别无序时别用 |
| 分类对比 | 柱状（竖向） | 各地区 / 各渠道数值比较 | 类别 >12 改用横向条形 |
| 构成占比（≤5 类） | 饼 / 环 | 份额结构，分类少 | **>5 类禁用饼图** |
| 构成占比（6–10 类） | 横向条形（排序） | 分类略多 | 别硬塞饼图 |
| 构成占比（>10 类） | 排序表 + Top N 高亮 | 长尾分类 | 饼图完全失效 |
| 分布 | 直方图 | 连续变量分箱看集中趋势 | 类别数据不适用 |
| 相关性 | 散点 | 两数值变量关系 | 需说明相关非因果 |
| 地理 | 地图（无库降级表） | 带地区字段 | 内网无地图库→表格 |
| 单一关键数字 | 大数字卡 | GMV、转化率等 | 别为凑图而画图 |

**硬规则：** 饼图 / 环图分类数必须 ≤5；超过即按上表降级。这是选题点名的死线。

## 二、配色规范

- 背景：浅色（`#FFFFFF` / `#F7F8FA`）；正文 / 轴线：`#1F2329`；次要文字：`#6B7280`。
- 系列色（按顺序，区分度高、非红绿相邻）：`#2F6FED` 蓝、`#E8833D` 橙、`#2FA84F` 绿、`#9B5DE5` 紫、`#E23D3D` 红、`#00A6A6` 青。
- 对比度：正文与背景 ≥ 4.5:1；图例与背景 ≥ 3:1。
- 色盲友好：不用红绿单独区分两个系列；用形状 / 标签辅助。
- 禁止：渐变描边、阴影堆叠、3D 透视、霓虹色。

## 三、交互组件写法要点（原生 JS，无库）

- **筛选下拉：** `<select>` + `change` 事件，按选中维度过滤数据数组后重绘。
- **维度切换：** 同一份数据用不同 `groupBy` 重算，切换时不刷新整页，只更新图表区。
- **重绘策略：** 图表用内联 SVG / Canvas 绘制；数据变化后清空画布重画，避免引外部库。
- **KPI 卡：** 顶部 3–4 个大数字，配同比 / 环比（↑/↓ + 百分比），用纯文字与色块，不依赖图表库。
- **响应式：** 用 `viewBox` 让 SVG 自适应宽度；容器用 `max-width` 居中，移动端可纵向堆叠。
- **可读性兜底：** 筛选无结果时显示「当前条件无数据」，不显示空白图。

## 四、常见误选与纠正

| 误选 | 问题 | 纠正 |
|---|---|---|
| 12 类做饼图 | 看不清 | 横向条形 + 排序 |
| 趋势用柱状无时间顺序 | 误导 | 折线，时间横轴 |
| 相关性用饼图 | 语义错 | 散点 |
| 所有图一种样式 | 无重点 | 主图突出 + 次要图弱化 |
| 引 CDN 图表库 | 离线白屏 | 内联 SVG/Canvas |

## 五、布局与排版规范

- **栅格：** 顶部 KPI 卡用 3–4 列等宽网格；主图区占满宽或 2 列；筛选区固定顶部，不随滚动消失。
- **留白：** 卡片间距 ≥16px，内边距 ≥16px；不塞满视口，四周留呼吸感。
- **字号：** 标题 20–28px、KPI 数字 28–36px、轴标签 12–14px、正文 14px；层级靠字号而非颜色区分。
- **字体：** 用系统字体栈（`-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`），不引外部字体保证离线。
- **数字格式：** 大额用千分位、同比环比带 ↑/↓ 与颜色（涨绿跌红或反之，但需标注口径）；避免无意义小数位。

## 六、可访问性兜底

- 图表旁配一行纯文字摘要（如「GMV 连续 3 月上升，8 月达 1.12 亿」），方便读屏与快速浏览。
- 交互元素有可见焦点态（focus 边框），键盘可操作筛选下拉。
- 颜色之外用标签 / 形状辅助区分系列，照顾色盲用户。
- 无数据 / 筛选无结果时显式提示，不显示空白或报错图形。

## 七、一页看板自检清单

1. 饼图类是否全部 ≤5 类？
2. 每个图是否都能在决策表里找到依据？
3. 是否零外部 CDN（全内联）？
4. 浅色下对比度是否达标？
5. 是否标注数据来源、口径、时间范围？
6. 筛选 / 维度切换是否真的能改图（不是摆设）？
7. 是否有文字摘要兜底，便于快速浏览？
