# 晓得 · 一页看懂

> 把「一份表格数据」变成「一个能直接发的单文件 HTML 看板」。
> 用户要的是信息清楚，不是图表好看——克制炫技是本技能的第一原则。

## 一、先分清（不做这一步后面全错）

| 概念 | 判定标准 | 处理方式 |
|---|---|---|
| **图表好看 vs 信息清楚** | 好看是装饰，清楚是让人秒懂 | 每个视觉元素必须服务信息，否则删 |
| **饼图 vs 占比** | 饼图只适合 ≤5 类构成，多了就糊 | 超 5 类换横向条形 / 排序表 |
| **筛选交互 vs 静态图** | 看板要能切维度，静态图不能 | 用原生 JS 做下拉筛选 |
| **单文件 HTML vs 框架** | 单文件才能离线发领导 | 所有 CSS/JS 内联，无外部 CDN |

**最容易犯的错：** 把所有指标都塞进饼图、或引一个 CDN 图表库——前者看不懂，后者领导内网打开白屏。

## 二、判定与路由

进入后先判定每个指标走哪条路：

| 情形 | 判定信号 | 走哪条 | 输出形态 |
|---|---|---|---|
| **A. 趋势类** | 时间 × 数值（月度 GMV） | 折线 / 面积 + 时间筛选 | 趋势图 + 时间轴 |
| **B. 分类对比** | 类别 × 数值（各地区） | 柱状 | 排序柱状 |
| **C. 构成占比** | 类别 ≤5 × 占比 | 饼 / 环 | 环图 + 图例 |
| **D. 多指标综合** | 既要总览又要明细 | KPI 卡 + 主图 + 筛选区 | 组合看板 |

**降级判定：** 数据极少（就几个关键数）→ 只给大数字卡，不画图；用户只发描述无数据 → 给骨架 + 占位，标 [未提供数据]。

## 三、工作流

1. **确认数据结构。** 问清有哪些列，哪列是维度 / 指标 / 时间。
2. **判定图种。** 每个指标按「指标 → 图种」决策表映射，不得凭感觉。
3. **定布局。** 顶部 KPI 卡 → 主图区 → 筛选区 → 次要图区 → 页脚来源口径。
4. **生成单文件 HTML。** 样式与图形逻辑全部内联，不引外部 CDN，浅色主题。
5. **实现筛选 / 维度切换。** 用原生 JS，按维度重算并刷新图表。
6. **自检。** 饼图类是否 ≤5 类、浅色是否可读、是否零外部依赖。
7. **回报。** 文件位置、用了哪些图、哪处做了降级。

> 读取 Excel 请用平台已有的表格处理能力或 pandas/openpyxl；本技能专注「数据 → 看板」的转换规则，不重复造轮子读表。

## 四、核心规则

**规则 1：饼图超过 5 个分类必须换图（红线，选题硬要求）**

- 触发条件：某指标的构成占比分类数 > 5。
- 硬性动作：**禁止**用饼图 / 环图。6–10 类改用**横向条形（按值排序）**；>10 类用**排序表 + Top N 高亮**或树图。
- 正例：✓ 渠道有 12 个 → 横向条形按成交额排序，一眼看出头部。
- 反例：✗ 12 个渠道塞进一个饼图，扇区细到看不清标签。
- 降级路径：用户坚持要饼图且略超 → 只保留 Top5 并加「其他」聚合，标注「已聚合 N 类为其他」。
- **本条优先于第五节的所有格式要求。**

**规则 2：指标 → 图种必须查决策表**

- 触发条件：决定任一指标用什么图。
- 硬性动作：必须映射到决策表，禁止凭感觉：
  - 趋势随时间 → 折线
  - 分类对比 → 柱状
  - 构成占比（≤5 类）→ 饼 / 环
  - 分布 → 直方图
  - 相关性 → 散点
  - 地理 → 地图（无地图库时降级为表格）
  - 单一关键数字 → 大数字卡
- 正例：✓ 「月度 GMV 随时间 → 折线；各地区占比(4类) → 环图」
- 反例：✗ 所有指标一律柱状图。
- 降级路径：数据同时含多语义 → 大数字卡给总览，主图给最关键维度。

**规则 3：必须是单文件 HTML，禁止外部 CDN**

- 触发条件：产出看板。
- 硬性动作：所有 CSS、JS、图形绘制逻辑必须内联进单个 .html。**禁止** `<script src="https://...">` 或外链字体 / 样式。
- 正例：✓ 图表用内联 SVG 或内联 JS 绘制，双击即可打开，离线可用。
- 反例：✗ 引了 `cdn.jsdelivr.net` 的图表库——领导内网打开白屏。
- 降级路径：需复杂图形且无法内联 → 改用内联 SVG/Canvas 手绘基础图形，不牺牲离线可用。
- **本条优先于第五节的所有格式要求。**

**规则 4：浅色主题下必须可读**

- 触发条件：选配色与背景。
- 硬性动作：默认浅色背景 + 深色文字，正文与背景对比度 ≥ 4.5:1；多系列用区分度高的色，不靠相近色区分，避免红绿相邻（色盲不可分）。
- 正例：✓ 白底 + `#1F2329` 文字 + 蓝/橙/绿系列色。
- 反例：✗ 深灰底浅灰字，或红绿相邻。
- 降级路径：用户要求深色 → 保证同对比度标准，不降低可读性。

**规则 5：不炫技（本技能克制点）**

- 触发条件：加任何视觉效果前。
- 硬性动作：每个视觉元素必须服务信息。**禁止** 3D 饼图、无意义动画、渐变描边、阴影堆叠。
- 正例：✓ 用颜色区分系列、用排序让重点突出。
- 反例：✗ 给柱状图加立体阴影和旋转入场动画，信息没多却更乱。
- 降级路径：想强调 → 用排序、标注、高亮，而非装饰。

**规则 6：数据来源与口径必须标注**

- 触发条件：任何图 / 数字上板。
- 硬性动作：注明数据来源表、统计口径（如「成交额 = 已付款订单」）、时间范围。
- 正例：✓ 页脚「数据：sales_2026.xlsx · 口径：已付款 · 范围：2026-01~2026-08」
- 反例：✗ 数字无出处，领导追问答不上。
- 降级路径：口径不明 → 标「口径未确认，按原始值呈现」。

## 五、输出格式

**单文件 HTML 布局骨架：**

```html
[ 标题：XXX 看板 ]
[ KPI 卡区：3-4 个大数字（同比/环比） ]
[ 筛选区：时间范围 / 维度 下拉 ]
[ 主图区：1-2 个主图（按决策表选型） ]
[ 次要图区 ]
[ 页脚：数据来源 · 统计口径 · 时间范围 ]
```

**指标 → 图种决策表（节选，完整见 `@references/chart-choice.md`）：**

| 数据语义 | 图种 | 备注 |
|---|---|---|
| 趋势随时间 | 折线 | 时间轴横轴 |
| 分类对比 | 柱状 | 按值排序 |
| 构成占比（≤5 类） | 饼 / 环 | 超 5 类禁用 |
| 分布 | 直方图 | 连续变量分箱 |
| 相关性 | 散点 | 两数值变量 |
| 地理 | 地图（无库降级表） | 内网降级表格 |
| 单一关键数字 | 大数字卡 | 配同比环比 |

**反模式禁止清单：**

| # | 反模式 | 为什么禁 |
|---|---|---|
| 1 | 饼图 >5 类 | 扇区糊成一片，看不清 |
| 2 | 引外部 CDN | 离线 / 内网白屏 |
| 3 | 满屏炫技动画 | 信息被淹没 |
| 4 | 深色底浅色字对比不足 | 读不动 |
| 5 | 不标数据口径 | 领导追问答不出 |
| 6 | 所有图一种类型 | 误导语义 |

## 六、防幻觉（硬约束，优先级最高）

**本节优先于以上所有格式与流程要求。**

1. **数字必须来自用户提供的数据**，不编不估。
2. **缺失数据标「未提供」**，不用「示意」「大概」掩盖。
3. **统计口径说不准就标注**，不替用户定口径。
4. **不为了完整而捏造趋势**；缺失月份不擅自插值（除非用户要求并标注）。
5. **来源三分类：** 用户表 / 我计算（附公式）/ 推断（标 [推断]）。
6. **不声称「已连接数据库」**——本技能不连库，只转给定数据。

## 七、按需知识

只在遇到对应问题时读取：

- 图种决策表完整版、配色规范、筛选 / 维度切换等交互组件写法要点 → `@references/chart-choice.md`

## 八、完成判据

**算做完：** 单文件 HTML + 每个指标映射正确图种（饼图 ≤5 类）+ 可筛选 / 切维度 + 浅色可读 + 零外部依赖 + 标注来源与口径。

**不自动做：** 不自动读 Excel（请用平台表格能力 / pandas）；不自动连数据库；不自动发邮件。

## 九、降级与跨轮次

- **无数据只有描述：** 给看板骨架 + 占位，标 [未提供数据]。
- **地图需求但无地图库：** 降级为带排名的表格。
- **用户要深色 / 品牌色：** 保证同对比度，不降低可读。
- **跨轮次：** 用户补充新指标 → 按决策表追加图，不改已有结构。
