# 作词手艺手册：意象、句式、钩子、改词

> 只在遇到对应问题时读本文。**体裁押韵表在 `@references/genres.md`，动笔前先查那张。**

---

## 一、意象：从抽象情绪到可拍画面

### 1.1 核心手法：具象名词 + 抽象动词

抽象情绪直接写出来是空的，**把它挂到一个具体物件上**就有了画面。

| 抽象 | 改造后 |
|---|---|
| 思念 | 思念生锈 |
| 孤独 | 热闹的荒凉 / 拥挤的孤独 |
| 时间 | 旧T恤晒得发白 / 六楼的灯亮了又灭 |
| 释然 | 把伞留在门口 |

### 1.2 五类可用的具体素材（按可靠性排序）

| 类别 | 例 | 可靠度 |
|---|---|---|
| **声音** | 锅铲刮锅底、电梯到站的叮、楼下电动车刹车 | ⭐⭐⭐ 最不易撞车 |
| **温度** | 凉掉的粥、贴脸的手、结霜的窗 | ⭐⭐⭐ |
| **触感** | 起球的毛衣、硌手的扶手 | ⭐⭐⭐ |
| **光** | 路灯下的雨、反光条、窗帘缝的光 | ⭐⭐ 略常见 |
| **大词**（星星 / 月亮 / 大海） | — | ⭐ **空泛，换成你身边能摸到的东西** |

### 1.3 国风意象库（用前先问：它服务哪种情绪）

- **山水**：江月、孤雁、长亭、渡口、晚风、暮雪
- **人事**：红笺、青衫、烛火、旧檐、流年、浮生
- **器物**：铜镜、孤舟、油纸伞、折扇、旧信封

⚠️ **国风最大避雷点：不要堆砌辞藻。** 所有古典画面必须服务**一种**情绪
（思念 / 遗憾 / 江湖洒脱），否则空洞廉价。

### 1.4 通感修辞（把一种感觉写成另一种感官）

> 「心跳声像秒针敲打玻璃」＝听觉 → 触觉/听觉
> 「思念是苦中带甜的柠檬茶」＝情感 → 味觉
> 「消毒水的味道让我想起医院」＝嗅觉 → 记忆

**用法**：一首歌里 1–2 处即可，多了会腻。

### 1.5 矛盾修辞（副歌张力的来源）

> 拥挤的孤独 / 最温柔的伤口 / 热闹的荒凉 / 说好不哭的人哭了

⚠️ 只在**副歌**用（主歌用会显得用力过猛）。

## 二、默认禁用清单（AI 味最直接的来源）

**这些词一旦出现，整首歌就「像 AI 写的」**。除非用户明确要，否则禁用：

| 类别 | 词与意象 |
|---|---|
| **光污染** | 霓虹、灯光、城市光、烟花 |
| **破碎类** | 破碎、崩塌、碎裂、支离破碎 |
| **时间占位** | 永恒、永远、今晚（当韵脚用）、某一天 |
| **眼神类** | 迷失在某人眼里、倒映在瞳孔 |
| **陈词** | 心如刀割、如鲠在喉、泪如雨下、撕心裂肺 |
| **万能句式** | 你和我一起、你终于明白、我还在原地 |

**纪律：禁用清单 + 必需物清单成对使用。**

> 只禁用 → 模型会在剩下的空间里继续偷懒。
> 配必需清单 → 逼出具体名词。
>
> 例：禁用上表全部 + **「这首歌必须出现：一杯凉掉的咖啡、一个航班号、一个停车场、一颗松掉的衣扣」**。

### 2.1 用户自己的禁忌优先

用户给了禁忌清单，**以用户的为准**，本文的默认清单退为参考。

## 三、中文句式与顿点（中文歌的隐形骨架）

### 3.1 常见句式与切分

| 句式 | 常见切分 | 适配 | 例 |
|---|---|---|---|
| **四言** | 2+2 | 短促、好记 | 意味 / 阑珊 |
| **五言** | 2+3（沉稳）/ 3+2（灵动） | 国风、叙事 | 明月 / 几时有；把酒 / 问青天 |
| **七言** | 4+3（最稳）/ 2+2+3（R&B、中快） | **华语流行主力** | 想你时 / 你在天边 |
| **八言** | 4+4 | 副歌大段抒情 | 开了灯 / 眼前的模样 |
| **长句** | 不强求工整 | 叙事、抓逻辑重音 | 抓**换气口** |

### 3.2 顿点纪律

- **同一段素材，把两种切分都试读一遍**，选最贴合旋律呼吸的那个
- 同一段内交错切分，**比通篇一种更鲜活**（避免工整带来的呆板）
- 长短句穿插：长句叙事、短句戳情绪 → **层次立刻拉开**

### 3.3 字数参考

| 段落 | 每句字数 |
|---|---|
| 主歌 | 5–9 字 |
| 副歌 | 7–11 字 |
| 古风 | 可长句化 |
| 民谣 | 可口语化，可放宽 |

**破格只给情绪需要的那一句**（爆发句突然变长/变短）。

### 3.4 「念」比「读」重要

写完**大声念出来**。念着顺，唱才会顺；念着卡，是句子太长或重音不对。

## 四、钩子（hook）四型

副歌是钩子的载体。**先定钩子，再写副歌。**

### 4.1 环形句 Ring phrase

首尾用同一句短语，给听者「完成感」。

> 不要叫我 ← → 不要叫我

### 4.2 列表升级 List escalation

给三样递进的东西，**第三样最狠**。

> 我留了你的外套、你的马克杯、和你说要删掉的那个号码

### 4.3 金句

一个带矛盾的判断句。

> 我走进去像付了钱要被看见 / 我的笑有收据

### 4.4 回扣句 Callback

把主歌的意象拧一下再出现，听众会有「原来如此」的快感。

> 主歌一：植物还朝着窗户倾斜 → 副歌：植物现在朝着门倾斜

### 4.5 钩子的三条硬指标

1. **3–10 字**，能独立站住
2. **落在长音或强拍**上（别埋在密集小字里 —— 埋了就记不住）
3. **开口元音多**（好唱、好记）

## 五、五种叙事框景（第二步用）

不要直接写词，先给**五个切入角度**，每个只出**标题 + 一句方向**：

| # | 框景 | 说明 |
|---|---|---|
| 1 | **一封信** | 写给某人或某物；口吻一旦定下，全篇不会飘 |
| 2 | **一次通话** | 对方说的最后一句话 |
| 3 | **一个房间的某个时刻** | 记忆里的具体空间 |
| 4 | **一段独白** | 没说出口的那段话 |
| 5 | **一段没发生的对话** | 如果那天说了会怎样 |

**锁定纪律**：用户挑定后**锁死框景**，主歌一必须在这里；主歌二换场景但**不换情绪核心**。

> **多视角写作**（进阶）：主歌一 = 叙述者，主歌二 = 被说的人，桥段 = 两个声音之间的空隙。
> ⚠️ 危险在于让模型自己决定何时换视角 —— **必须逐段指定谁在说话**，否则听众会跟丢。

## 六、改词手法（跨轮次用，只改该改的）

### 6.1 五种改法（按优先级）

| # | 手法 | 做法 |
|---|---|---|
| 1 | **换框景** | 抽象→具体（规则 1） |
| 2 | **换动词** | 「很孤单」→「把伞留在门口」 |
| 3 | **调句长** | 情绪需要爆发句才加长 |
| 4 | **挪韵脚** | 硬押的那句移出不押韵的位置 |
| 5 | **换韵不改词** | 用近韵收尾而不是掰语法 |

### 6.2 改词交付格式（必须带）

```text
改前：<原文>
改后：<新文>
理由：<为什么这么改 —— 指向具体规则>
影响：<只动了第几段，别处未改>
```

### 6.3 三条纪律

- **只改对应段落**，不整首重写（整首重写的代价是前面调好的也要重调）
- 改完**重跑校验**（改韵脚可能引入新的硬押）
- 用户说「整首推翻」时，**先问清他嫌的是哪一部分**再动手

## 七、快速自检清单（人读部分）

- [ ] 每个情绪都落到了具体画面/动作上？（删掉情绪词，画面还在吗？）
- [ ] 有没有撞禁用清单里的词？
- [ ] 押韵方案查过体裁表，不是凭记忆？
- [ ] 主歌二换了场景，不是主歌一的逐句改写？
- [ ] 副歌有一句 3–10 字、能独立站住的钩子？
- [ ] 有没有为押韵掰语法、生造词？
- [ ] 同段句长规律，破格只有情绪需要的那一句？
- [ ] 大声念过，念着顺？
- [ ] 有没有编造具名实体、真实事件？
- [ ] 有没有承诺效果？
