# 体裁 × 押韵方案 × 句式 × 纪律（写之前必查这张表）

> **核心一条：没有普适默认。** 每种体裁有自己的押韵约定 —— 给民谣 ballad 用 AABB 密集尾韵、
> 给说唱用「押韵少一点」，都会露出外行感。**动笔前先查本表，别用你记忆里的流行歌习惯。**

---

## 一、总表（12 体裁）

| 体裁 | 默认押韵方案 | 严格度 | 句式特点 | 必守纪律 |
|---|---|---|---|---|
| **流行 Pop** | 自由（常XAXA / ABAB） | 低 | 7–11 字/句，对仗不严 | 副歌用开口韵；近韵优于硬全韵 |
| **民谣 Folk** | ABCB（歌谣四行） | 中 | 叙事句，5–9 字 | **每行都押韵是错的** —— ABCB 是 2/4 押 |
| **Ballad** | ABCB 或 ABAB | 中 | 长句叙事，句长可起伏 | 句长起伏要有理由（叙事推进） |
| **摇滚 Rock** | ABAB 或 AABB | 低 | 短句有力，可重复 | 意义优先于押韵；重复句即副歌 |
| **朋克 Punk** | AABB（宽松） | 低 | 极短句、喊唱 | 半押韵（half-rhyme）本身就是风格 |
| **金属 Metal** | 可选 | 极低 | 念白式、音节密度优先 | 可以几乎不押；力量感来自音节密度 |
| **说唱 / 嘻哈 Rap** | **AABB 对句 + 句内韵密集** | **高** | 每行字数**必须严格对齐**（flow 优先） | ★ **多音节押韵（multisyllabic）与句内韵是硬要求**，不是加分项 |
| **R&B / 灵魂** | 灵活 | 低 | 音节多、咬字重要 | **情绪优先**；押韵让位给转音与气口 |
| **放克 Funk** | 极少 | 很低 | 念白化、随节奏走 | 几乎不押，靠节奏与重复 |
| **电子 / EDM** | 重复 > 押韵 | 极低 | 短句循环 | 重复同一句做 hook；押韵不重要 |
| **氛围 / Lo-Fi** | 无 | 无 | 破碎句、留白 | 不强求完整句；意象碎片化 |
| **爵士 Jazz** | AABA（32 小节） | 高（技巧型） | 用歌诗与标准曲惯例 | 靠近歌诗语法但用现代词；避免平白叙述 |
| **布鲁斯 Blues** | **AAB（三行式）** | 中 | 重复句 + 应答句 | ★ 三行结构是体裁标志；`AAB` 的 B 行常重复 A 的词 |
| **乡村 Country** | ABCB | 中 | 叙事、口语 | 近韵可用；叙事直白不丢人 |
| **Reggae / Dancehall** | Riddim 驱动 | 中 | 依节奏念 | 押韵服从节奏位 |
| **Afrobeats** | 呼应式（call & response） | 低 | 短句重复 | 重复 + 应答是骨架 |
| **福音 Gospel** | 渐进重复 | 低 | build 式层层叠加 | 重复段落加新词，是结构手法 |
| **古风 / 国风** | 抱韵（A-B-B-A）或交韵 | 中高 | 五七言、对仗 | ★ **意象必须服务一种情绪**，堆辞藻即廉价 |

## 二、韵脚五型（混着用，别只用一种）

| 类型 | 定义 | 例 |
|---|---|---|
| **全韵 Perfect** | 完全相同 | 冷 / 静 |
| **近韵 / 斜韵 Slant** | 韵腹近、韵尾不同 | 丢 / 走 |
| **头韵 Assonance** | 韵母相同 | lake / fate |
| **尾韵 Consonance** | 韵尾相同 | blank / think |
| **句内韵 Internal** | **一行之内**押 | 「fire and desire higher」 |

**纪律**：

- **全韵密集会像儿歌**；**全是斜韵会显得懒**。混着用，全韵留在一两个关键位置。
- **句内韵是说唱与Trap 的主力**，流行歌里用作调剂（一段里 1–2 处即可）。
- **押韵密度有别**：主歌**低密度**，预副歌/副歌可以升高，副歌在情绪转折处放一个全韵最有力。

## 三、押韵方案字母表

| 方案 | 结构 | 听感 |
|---|---|---|
| **AABB** | 两行一押 | 稳、当场解决 |
| **ABAB** | 隔行押 | 经典、延迟解决 |
| **ABCB** | 偶数行押 | 松、叙事感强（民谣-ballad 标准） |
| **AAB** | 三行式 | 布鲁斯标志（第三行重复第一行或应答） |
| **AAAAX** | 四行同韵 + 意外收尾 | 强铺垫、反转收尾 |
| **XAXA** | 松散 | 口语感（流行/摇滚常用） |
| **AABA** | 三行同 + 变奏 | 爵士标准（32 小节） |
| **抱韵 ABBA** | 首尾同韵、中间另韵 | 中文韵文传统，环形呼应 |

## 四、为什么会有这张表（原理）

**韵脚的功能是给听者「预期」**：押上了预期被满足，不押则制造推进。
体裁之间的差别，本质上是**对「预期被满足」的容忍度**不同：

- **说唱**要押得密 —— flow 靠韵脚撑，不押就散
- **R&B** 押得松 —— 情绪靠转音与气口撑，押韵会打断演唱
- **布鲁斯** 必 AAB —— 重复是体裁的语法
- **Lo-Fi** 干脆不押 —— 破碎本身就是气质

**推论**：**「押韵好不好」必须放在体裁里问**。同一段词换个体裁就可能完全不合格。

## 五、方案与体裁冲突的三种典型翻车

| 翻车 | 表现 | 修法 |
|---|---|---|
| 给民谣 ballad 用密集全韵 | 每句都在喊，像儿歌 | 改 ABCB，押 2/4 行 |
| 给说唱用抒情式散押 | 词写得好但唱不出 flow | 改严格 AABB + 补句内韵 |
| 给古风堆辞藻 | 通篇意象、无情绪落点 | 每个意象必须指向同一种情绪；砍掉无用的 |

## 六、中文专属：十三辙与开口度

**十三辙**（按韵母归类，传统说唱与戏曲的韵部划分）：
`发花 / 梭波 / 乜斜 / 一七 / 姑苏 / 怀来 / 灰堆 / 遥条 / 由求 / 言前 / 人辰 / 江阳 / 中东`

- **副歌优先开口辙**：江阳（ang）、言前（an/ian）、怀来（ai）、遥条（ao）—— 开口大，情绪顶得上去
- **主歌可用闭口辙**：一七（i/ü）、姑苏（u）、由求（ou）、中东（ong/eng）—— 细腻
- ⚠️ **粤语与英文另有开口度体系**，别直接套普通话十三辙 —— 粤语六声调、英文元音开口度另算。

## 七、查表之后：把这套约定变成可执行判据

`lyric_check.py` 能机检的部分（其余靠人读）：

| 能机检 | 怎么判 |
|---|---|
| **同段内押韵方案是否一致** | 抽每段尾字韵母，看是否中途换辙 |
| **押韵密度** | 全韵密度过高 → WARN（提示「像儿歌」） |
| **是否几乎不押** | 押韵率为 0 且体裁要求押韵 → WARN |
| **句长规律** | 同段字数方差过大 → WARN |
| **禁用词** | 扫描陈词滥调清单 |
| **hook 句长度** | 副歌中 3–10 字的独立句是否存在 |
| **硬押** | 尾韵与同韵近义词替换后句意破坏（需人读） |

**不能机检、必须人读的**：画面是否成立（规则 1）、主歌二是否真发展（规则 4）、
语义是否被韵脚破坏（规则 3）—— 这三条是**语义判断**，脚本不碰。
