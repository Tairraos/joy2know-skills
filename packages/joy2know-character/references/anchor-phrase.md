# 锚点短语（Anchor Phrase）写法与判据

## 一、是什么

锚点短语是一段**必须逐字出现在每条提示词正文里**的最小名词短语，通常是「颜色 + 材质/形制 + 物体」。它负责让同一个角色跨镜头、跨对话长相一致。

- 合格：`pale blue chunky knit wool sweater`
- 结构：颜色(pale blue) + 材质/形制(chunky knit wool) + 物体(sweater)

## 二、上锁三条判据（三条全中才上锁）

1. **在 2 个以上镜头出现**——只出现一次的 transient 细节不值得锁。
2. **观众能看出不一致**——发色瞳色服装算，背景里一闪而过的杯子不算。
3. **不随剧情改变**——会变的是「状态」，状态不上锁。

## 三、写法硬约束

- **最小名词短语**：只保留「颜色+材质/形制+物体」。
- **禁止**含：句号、动作、状态、数量、剧情。
- **禁止**空泛质量词：`high quality`、`detailed`、`帅气`、`高级感` 不是可辨识事实。
- **禁止**完整句子：句子下一镜必改写，锁当场失效。

## 四、正反例对照

| 类型 | 写法 | 评价 |
|---|---|---|
| 正 | `pale blue chunky knit wool sweater` | 颜色+材质+物体，可逐字匹配 |
| 正 | `round black framed glasses` | 形制+颜色+物体，稳定 |
| 反 | `蓝色毛衣` | 区分不了浅蓝藏青，英文提示词匹配不上 |
| 反 | `她穿着浅蓝毛衣站在窗边` | 整句，下一镜必须改写，锁失效 |
| 反 | `high quality, detailed` | 不是可辨识事实，毫无锁定作用 |
| 反 | `wet hair`（湿发） | 是状态，随剧情变，不该上锁 |

> 两个反例只差一个维度：左列错在「颗粒度太粗/带了剧情/不是事实/是状态」，右列是合格写法——对照着改。

## 五、校验方法（写完后必须跑一遍）

1. **逐字比对**：把短语贴进拟好的提示词，确认一字不差地出现（含连字符、空格）。
2. **可生成性**：遮掉角色名，仅凭这条短语能否画出该物体？不能 → 太抽象，退回补材质。
3. **可比较性**：两镜都放这条短语，生成结果该物体是否一致？不一致 → 颗粒度仍粗，加材质细节。
4. **状态排除**：确认短语里没有表情/姿势/破损等会变的词。
5. **双语一致**（若模型吃中文）：中英两版指向同一事实，不意译。

## 六、一个角色一把锁，换造型另起

- 同一角色两套固定外观 = 两把锁，各自独立 `locked_anchors`。
- 只是配饰微调（换围巾颜色）→ 在现有锁内新增一条短语，不算新造型。

## 七、从参考图提炼锚点短语的步骤

1. 列外观：把能稳定看见的服装/发型/配饰逐件列出。
2. 去虚词：删掉「漂亮/帅气/有气质」等质量词，它们不可辨识。
3. 加材质：把「蓝毛衣」补成「pale blue chunky knit wool sweater」，补全颜色与材质。
4. 过判据：逐条问「2 镜以上出现？观众能看出不一致？不随剧情变？」三条全中才留。
5. 排状态：把表情/姿势/湿身/破损移进 `state_excluded`，不进锁。
6. 双语校验：若模型吃中文，确认中英两版指向同一事实、不意译。

## 八、常见翻车现场

- 锁面写「蓝色毛衣」→ 英文 prompt 永远匹配不上，且分不出浅蓝藏青。
- 锁面写完整句子 → 下一镜必须改写，锁当场失效。
- 锁面写质量词 → 不是事实，等于没锁。
- 把「湿发/破损」锁死 → 剧情一变，锁逼着错误复现。
