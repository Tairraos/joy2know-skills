## 四、门 3 · 合理性结论

- **规则是否自洽**：✅ 无互相打架。SKILL.md 规则 1（先有 token 文件）与规则 4（页面只 `var()` 引用）、规则 5（多页只增不重写）同一取向；token-spec.md 的「命名前缀表」与「分级数量表」内部无矛盾（如 `--gray-` 50/100/300/600/900 与 §3 五级描述一致）。
- **推断是否标注为推断**：⚠️ 脚本不产出 token、不补推断值，故本项对脚本**天然成立**（它只报频次，不猜结论，符合脚本 docstring「只做统计不做判断」）。但 SKILL.md 规则 2/3/§六 要求的「`[推断]` 标注」是 **AI 生成 token 时的纪律，本地无触发环境、无法实测**——列作未覆盖。
- **错误提示是否可指导下一步**：✅ 抓取失败打印「发生了什么（异常类型+原因）+ 你可以怎么做（确认 URL/改用截图/不要编造）」，不抛裸堆栈；空/无 CSS 给 SPA 转向建议。符合「发生了什么 + 怎么办」。
- **边界是否优雅**：✅ 大体优雅（空/无 CSS/缺 href/不存在/非法/超大均不崩，失败走退出码 2）；⚠️ 仅非 UTF-8 有轻度降级（见六·缺陷 2）。
- **零依赖是否守住**：✅ 仅标准库，已 grep 核实无外部包 import，与声明一致。
- **值来源是否可追溯**：✅ 脚本输出「来源：<url>」「内联：有/无 外链：N 成功 M」「抓取失败的外链：…」，可追溯每类候选来自内联还是外链；不编造。SKILL.md 要求的「用户/提取/推断」三源标注是 AI 写 token 时的纪律，未在脚本层实测（未覆盖）。

**已知缺陷**（**消解情况见本节末「修复记录」**）：

- **【已修 2026-09-23】** **缺陷 1（轻）· `--css-only` 是空操作**：脚本 docstring（第 16 行）与 argparse 都声明了 `--css-only`，
  但 `report()` 函数第三个形参 `css_only` **在函数体内从未被引用**，导致该旗被接受却对输出零影响
  （与不加该旗输出逐字节一致）。属「文档（脚本自身用法说明）写了、实现没做」。
  建议：要么在 `report()` 里真正实现「只抓 CSS 不抓 HTML」的语义，要么从 docstring/argparse 删掉该旗。
- **【已修 2026-09-23】** **缺陷 2（轻）· 非 UTF-8 静默按 UTF-8 替换解码**：`fetch()` 仅从 `Content-Type` 的 `charset=` 取编码，
  取不到（含 `file://` 场景）就默认 utf-8 + `errors="replace"`。GBK 等页面**不会崩**，但非 ASCII 内容（如中文）
  被替换符吃掉且无提示——所幸 CSS 候选值多为 ASCII 能幸存。建议：对解码失败或 `file://` 增加 `chardet` 探测
  （会破零依赖）或至少在输出里提示「非 UTF-8，非 ASCII 内容可能丢失」。

> **严重度判定说明**：以上两条均为**轻级**，不影响主流程（正常 UTF-8 网页 + `--limit`/`--timeout` 全绿），
> 也不影响包可上传——故判为「非硬缺陷」，状态取 `⚠️ 有条件通过`。若维护者认为 `--css-only` 死旗属「文档与实现不符」硬伤，应改判并优先修。

**【已修 2026-09-23 · 版本 1.1.0 → 1.2.0】修法与验收**：

- **缺陷 1 已修（选「补实现」而非删旗）**：`report()` 在 `css_only=True` 时**只输出「CSS 变量（令牌）」一段**，
  并在末尾留痕注明「颜色/字号/间距/圆角/阴影/字体族候选已跳过」；`argparse` 的 help 与脚本 docstring 同步改成
  与真实行为一致（原文写「只抓 CSS，不抓 HTML」——那是**另一种语义**，与实现不符，属 R3 违规，一并改掉）。
- **缺陷 2 已修**：新增 `sniff_charset()`，按 **HTTP `Content-Type` 的 charset → 页面 `<meta charset>` →
  CSS `@charset`** 三级嗅探；解码顺序改为「先 `strict` 试解，解不开才 `errors="replace"`」，且**每次降级都在
  stderr 打编码警告**（写明影响「非 ASCII 内容可能丢失」与下一步「改用截图」）。零第三方依赖保持不变。
- **同步文档（R3）**：`references/extraction-guide.md` 补 `--css-only` 语义与「编码嗅探 + 警告」说明；
