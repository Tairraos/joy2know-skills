# 默认治愈风格配方

## 一、为什么默认治愈

用户只说「写首歌」时，最容易翻车的是风格选择瘫痪——你给一堆选项，他一个都不满意。
治愈是最大公约数：接受面广、不容易出错、也最容易做出画面感。
**默认治愈不等于只能治愈。** 用户指定任何风格时，音乐外壳全换，只保留下面第三部分的文风内核。

## 二、音乐外壳（默认参数）

| 项 | 默认值 |
|---|---|
| Genre | Acoustic Indie Folk（可叠加 `Soft Pop`） |
| Vocal | Soft breathy female vocals（用户未指定时的默认；可换男声） |
| Instruments | Fingerpicked acoustic guitar + warm piano + light strings + subtle pads |
| Mood | Healing, warm, nostalgic |
| Tempo | 72–84 BPM（默认 76） |
| Atmosphere | Intimate room reverb, morning-light warmth |
| Production | Polished analog production |

**完整 Style 示例：**
```
Mandarin, Standard Mandarin Enunciation, Acoustic Indie Folk, Soft breathy female vocals,
Fingerpicked acoustic guitar + warm piano + light strings + subtle pads, Healing and nostalgic,
76 BPM, Intimate room reverb with morning-light warmth, Polished analog production
```

## 三、文风内核（换风格也不换这一层）

| 技法 | 做法 | 例子 |
|---|---|---|
| **主歌写实** | 用具体动词代替抒情，靠生活细节铺陈 | 「锅铲刮过锅底 / 是这十年最安稳的闹钟」 |
| **意象重组** | 具象名词 + 抽象动词 | 「思念生锈」「黄昏结痂」「孤独发霉」 |
| **副歌张力** | 矛盾修辞 | 「拥挤的孤独」「热闹的荒凉」「最温柔的伤口」 |
| **语气助推** | 语气词增加倾诉感 | 「啊」「呢」「吧」「哦」慎用，一句一个即可 |
| **韵脚分工** | 主歌闭口韵（细腻），副歌开口韵（高亢） | 主歌押 i/ü/en，副歌押 a/ang/ao |

## 四、三套预设（用户说「你看着办」时挑一套）

**A. 晨光** —— 醒来、和解、重新开始
- 意象：窗帘缝的光、凉掉的水、叠好的衣服
- 情绪：Healing, hopeful, tender
- BPM 78，木吉他为主，钢琴点缀

**B. 夜灯** —— 独处、想念、与自己和解
- 意象：台灯、冰箱的嗡鸣、凌晨三点的窗
- 情绪：Intimate, melancholic but warm
- BPM 72，钢琴为主，弦乐铺底

**C. 归途** —— 回家、父亲母亲、旧物
- 意象：旧皮鞋、站台、行李箱的轮子声
- 情绪：Nostalgic, gentle, storytelling
- BPM 80，吉他 + 轻打击乐

## 五、段落写法

```
[Intro – Muted piano loop, soft static crackle, distant rain]
[Verse 1 – Half-whispered, Intimate, Close-mic]
  写实细节 + 闭口韵
[Pre-Chorus – Build-up with rising strings, tense]
  情绪抬升，句变短
[Chorus – Grand and anthemic, Layered vocals, Wide stereo]
  矛盾修辞 + 开口韵
[Verse 2 – More melodic, Slight reverb]
  换一个生活场景，推进一层
[Bridge – Dramatic shift, No percussion, Bare vocals]
  抽掉伴奏，留一句最狠的
[Chorus – Final climax, Layered vocals]
[Outro – Fade out with echoing solo piano]
[End]
```

## 六、反例

| 反例 | 为什么不行 |
|---|---|
| 「我好想你 / 我真的好想你」 | 纯抒情无画面，AI 也唱不出层次 |
| 副歌押闭口韵 | 开口度不够，情绪顶不上去 |
| 全篇一种唱法 | 没有起伏，听感平 |
| 治愈歌里加 `distorted` `bitcrushed` | 与治愈质感直接冲突 |
| 意象全是「星星、月亮、大海」 | 空泛，换成你身边能摸到的东西 |
| 每段都写满 | 留白是治愈的一部分，主歌留一句空白给呼吸 |
