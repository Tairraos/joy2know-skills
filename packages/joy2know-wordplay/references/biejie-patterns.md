# 别解：两式、红线与写法

本文件是 `joy2know-wordplay` 的引用资料，回答"这个词能不能别解、按哪一式写、写到什么程度收手"。

---

## 一、别解是什么

**修辞格名，不是自造词。**

> **别解**：运用词汇、语法或修辞等手段，**临时赋予一个词语以原来不曾有的新义**。
> 又称奇解 / 曲解 / 谐解 / 套词 / 返源 / 望文生义。反义词是「**正解**」。

三条从定义直接推出来的事实，决定了这个技能的写法：

| 事实 | 对写作的约束 |
|---|---|
| 新义是**临时的**，离开语境就不成立 | 不要写成像在陈述定义（「X 是指…」）——那是正解的语气 |
| 它的对面是**正解**，不是「误解」 | 别解**不宣称自己更正确**。写了「其实」「真正的意思是」就变成了抢正解的位置 |
| 它是**有意的**、目的是打趣逗笑 | 不是"看错了"，也不是"故意歪曲"。**贬损性的曲解不算别解**，那是攻击 |

**它在哪些文体里是主场**：广告、笑话小品、谜语、标题、脑筋急转弯。
也就是说——**词卡、段子、一句话解释，正是它本来该出现的地方**，不是硬套。

## 二、两式的判定表

别解按构成手段分两类，**先判是哪一类再动笔**：

| 式 | 机制 | 怎么判 | 示范（写法示例，不是唯一答案） |
|---|---|---|---|
| **返源式** | 把词的整体义**拉回字面义相加** | 这个词是**复合结构**（字面各有意思）时优先 | 「内卷」→ 卷起来了，但没往外扩，只在原地卷 |
| **附会式** | 借词的**多义或谐音**，牵强接到另一个意思 | 词里有一个**多义语素**或谐音点时才可用 | 「打工人」→ 用青春换房贷的勇士 |

**判定顺序：先看有没有字面可拆 → 拆得出就用返源式（更干净、更少争议）→ 拆不出但有歧义语素 → 用附会式。**

两式的共同前提：**这个词已经有公认的用法**。没有公共语境的新造词、生僻术语，别解会退化成瞎编（§三）。

### 两式的失败形态

| 式 | 失败长相 | 怎么修 |
|---|---|---|
| 返源式 | 只是把词拆开念了一遍，没有新义 | 拆完必须**落到一个具体动作或画面上**，否则等于没写 |
| 附会式 | 谐音太远，读者要听你解释才懂 | 谐音点若需要解释，就换词——**别解不能靠脚注** |

## 三、不做清单（硬红线）

**以下五类一律不做，直接说明不适用并给出替代方案。** 这一条优先于用户的"就想听个损的"。

1. **真人姓名、在世的具体个人。**
2. **民族 / 地域 / 性别 / 职业群体的贬称或群体标签。**
3. **灾难、伤亡、公共卫生事件。**
4. **正在审理的案件、涉案当事人。**
5. **只能靠贬损某群人才成立的笑话。**

判定口径一句话：**别解的靶子只能是「词与概念」，不能是「人」。**
同一个词若只能靠踩一群人才好笑，那就不做——**换词，不换靶子。**

**不做时的输出**：说明为什么不做（一句话）+ 给这个词的**正经释义**或**建议换一个能做别解的词**。
不要做一个打折扣的版本。

## 四、写释义的五条纪律

1. **20–40 字，一句话。** 说不出成一句话，说明你自己还没想清楚。
2. **不许同义改写。** 写完自检：把原词换成近义词，这句还成立吗？成立 = 你只是复述，重写。
3. **不写「其实」「说白了」「真正的意思是」。** 一出口就从别解变成声称事实。
4. **不把结论落在名词上。** 「这就是 X 的本质」是最弱的收尾；落在**具体动作或画面**上才有劲。
5. **不堆形容词。** 加字要加在动作与画面上，不许靠「深刻的」「精准的」这类词凑长度。

### 释义自检（三条，30 秒做完）

- [ ] 读一遍会不会「咯噔」？不会 → 不够辣，回两式表重判
- [ ] 事实核对一遍：有没有编出来的数字 / 年份 / 人名 / 机构？
- [ ] 删掉这句，读者还知道这个词的意思吗？**知道 = 这句没带来新东西**

## 五、图解与释义的关系：哪些释义画得出图

**图解不是配图，是那句隐喻的「结构显影」。** 画不画的**判定只有一处**：
`SKILL.md` §四.2（含"什么时候不画"）。**本节不重复那条判据**，只补那里没有的东西 ——
**哪些释义天生带结构、画得出来**：

| 释义里的结构 | 图里画什么 |
|---|---|
| 循环 | 自环 / 回转箭头 |
| 交换 | 双向箭头 / 天平 |
| 压缩 | 宽进窄出 / 漏斗 |
| 断裂 | 断口 + 虚线接续 |
| 错位 | 两列不对齐的方块 |
| 叠加 | 同心 / 层叠 |

**这是「画得出」的清单，不是「必须画」的清单。** 释义落在表内、但对应表凑不出两条，
照样不画。

**装饰图的识别方法**：把图删掉，释义还成立吗？**成立 = 这张图是装饰，白画了。**
（这不是凭感觉——装饰图的定义就是"删掉不影响理解"，所以这个测试是定义的直接推论。）
本技能宁可交一张没有图的卡，也不要交一张有装饰图的卡。
