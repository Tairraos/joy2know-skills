## 一、两套画布：共用一份 y 轴节奏，只差宽度

两套画布**共用同一张 y 表**（下图所有 y 值两套通用）。差别只有三项：画布宽、卡片左右留白、「词」的字号。
**这就是"两套坐标不漂移"的实现方式 —— 只有一份 y 表，不存在第二处可改的地方。**

| # | 元素 | y（两套通用） | 说明 |
|---|---|---|---|
| 1 | 卡片底 | 上沿 16 / 下沿 **584** | 圆角 @16px，全卡唯一底色块 |
| 2 | 刊头「晓得·别解」 | **62** | 17px 楷体，字距 4，居中 |
| 3 | 分隔线 | **80** | 0.5px，两端各距中心 60（poster）/ 90（inline） |
| 4 | 拼音 | **116** | 13px，弱化色，居中。**拿不准就不写这一行** |
| 5 | 词 | **154** | 楷体，居中 |
| 6 | 语言行 | **180** | 12px，弱化色，居中。格式见 §二 |
| 7 | 释义（三行位） | **222 / 248 / 274** | 15px 楷体，行距 26。第 2、3 行可为空 |
| 8 | 图解区 | **300 → 470** | 净高 170，水平居中；**不得越界** |
| 9 | 图说 | **496** | 11px，弱化色，居中 |
| 10 | 页脚 | **548** | 11px，弱化色，居中。默认「一目晓得」 |

| 画布 | 宽度 | 卡片块 | 词字号 | 画布高 | 用途 |
|---|---|---|---|---|---|
| `poster` | **400** | x=16 w=368 | 32 | **600** | 竖版卡片，可下载可分享（默认） |
| `inline` | **680** | x=40 w=600 | 34 | 604 | 对话内预览 |

**正文可用宽度**：poster 312px / inline 544px。
→ poster 上**释义每行不超过 22 个汉字**（15px × 22 = 330 ≈ 上限）；inline 上不超过 36 字。超了就换行，不要缩字号。

## 二、字段与语言行

### 必填字段

| 字段 | 必填 | 缺了怎么办 |
|---|---|---|
| `--word` 词条 | ✅ | 没有词就没有卡 |
| `--pinyin` 拼音 | ⭕ | **拿不准就省略整行**，不许标错音 |
| `--en` 英文 | ⭕ | 能不写；写了就写完整，不写「…」 |
| 繁體值 | ✅ | 允许写「同形」，但**必须给一个值**（见下） |
| `--def` 释义 | ✅ | 1–3 行，第 1 行必填 |
| `--diagram` 图解 | ⭕ | 不给就不画（见 §三 的「不画」判据） |
| `--caption` 图说 | 有图解就该有 | 一句话说明这张图在说什么 |

### 语言行的三分支（必须落在其中之一）

```
English: Client / Party A  |  繁體：週報
English: Client / Party A  |  繁體：甲方（同形）
English: Key performance indicator  |  繁體：字母詞，繁簡同形
```

| CLI | 渲染结果 |
|---|---|
| `--trad 週報` | `繁體：週報` |
| `--trad-same` | `繁體：<词>（同形）` |
| `--trad-kind alpha` | `繁體：字母詞，繁簡同形` |
| `--trad-kind digit` | `繁體：數字詞，繁簡同形` |

**⚠️ 没有「粤语词」这一支，这是有意的。** 模型在同形词上极容易编一个"像香港话"的说法来填满那一行。
**拿不到可查来源就写「同形」。**

### 页脚

默认「一目晓得」。**卡片内不出现任何第三方作品名、作者名或来源说明** ——
署名与出处放在仓库级的版权说明里，不占卡片版面。`--no-footer` 可整行省略。

## 三、图解槽位与占位符

`--diagram` 传一个独立 SVG 片段文件（**不带 `<svg>` 外层**，只给 `<g>` 或裸元素），脚本把它插到图解区中央。

**片段里必须用占位符取色，不许自带色值：**

| 占位符 | 替换为 |
|---|---|
| `{{bg}}` | 本次底色 |
| `{{ink}}` | 墨色（主文字） |
| `{{soft}}` | 弱化色（次要文字 / 坐标轴） |
| `{{accent}}` | 强调色（图解主体） |

自带色值会与配色打架，并**突破 4 色上限**（底色 + 墨 + 弱化 + 强调已经是满额）。

### 图解不画时

**画不画的判据只有一个表述处**：`SKILL.md` §四.2。`@references/biejie-patterns.md` §五 只给
「哪些释义画得出图」的结构清单、不含判定。
**本文件不重复表述那条判据** —— 派生信息两处就会漂。

不画时：**不传 `--diagram` 即可**，其余部分照常出卡（卡面实际用 3 色：底 / 墨 / 弱化，强调色不出现）。

### 怎么选色

| 用法 | 行为 |
|---|---|
| `--palette auto`（默认） | **按词条哈希取色** —— 同一个词永远同一个色，不同词不同色 |
| `--palette sakura` | 指定某一套 |
| `--palette random` | 真随机（每次不同） |

**为什么默认是 `auto` 而不是随机**：同一个词反复出卡应该是同一张脸 —— 读者第二次见到才认得出来。
一个系列要统一，就固定写死一个色名。**真随机只在"一次出一批、想让它们看起来各不相同"时用。**

### 用色纪律

- 颜色只表达**类别**，不表达**好坏**。金融场景例外：红涨绿跌。
- 同一张图里两类关系用**实线 / 虚线**区分，不用颜色区分。
- 墨色与弱化色都是这套底色上的深色，**不要用纯黑**（`#000`）—— 会显得脏。

## 五、合规自检清单（交前必跑）

```bash
node scripts/card.mjs check --in card.svg
```

脚本逐条判下面 10 项，**任一项不过返回非 0，不许交付**：

- [ ] **1** 画布宽 ∈ {400, 680}，`viewBox` 与 `width="100%"` 都在
- [ ] **2** 每个图形元素**显式带 `fill` 或 `stroke`**（不带会退化成黑色）
- [ ] **3** `<polyline>` / `<path>` 必须显式写 `fill`（连线写 `fill="none"`）
- [ ] **4** 最小字号 ≥ **11px**
- [ ] **5** 去重后的颜色数（不含 `none`）≤ **4**
- [ ] **6** 无 emoji 字符
- [ ] **7** 无 HTML 注释、无 `<script>`、无 `on*` 事件属性
- [ ] **8** 无外部引用（不出现 `http`、`url(`、`xlink:href`、`<image>`）
- [ ] **9** `<title>` 与 `<desc>` 都存在
- [ ] **10** 刊头为「晓得·别解」、语言行含 `繁體：`，且**卡片文字里不出现署名 / 来源标记**
      （默认拦 `©` / `提示词框架` / `作者：` / `来源：`；**第三方作品名与作者名请用 `--forbid 甲,乙` 显式传进来**——
      裸词不进默认表，否则会误伤「来源不明的优越感」这类正常释义）

**跳过自检 = 没做。** 不能跑脚本时（无 node），按上一节手写 SVG 并**逐条人工核对**，
同时**明确告诉用户「本次未过 check」** —— 降级必须留痕。

### 另外两个子命令

```bash
node scripts/card.mjs palettes   # 打印 8 套配色的键与色值（不用去翻文档）
node scripts/card.mjs selftest   # 检查器自身的正向 / 反向用例，改动 check 或选色逻辑后必跑
```

`selftest` 覆盖三类，**项数由脚本自己数、不在文档里写死**：

1. **卡片合规**：正常卡通过（阳性对照）＋ 逐条篡改（画布宽 / `fill` / 字号 / 颜色数 / emoji /
   注释 / `script` / 外链 / `desc` / 刊头 / 繁體行 / 署名标记 / `--forbid`）各应被驳回；
2. **选色稳定性与分散度**：拿 `SAMPLE_WORDS`（一批真实中文热词 / 职场词 / 缩写词，**不许缩减**，
   样本太小会把噪声当成结论）走**真实选色路径**取两次色，逐词须一致；且 8 套色全可达、
   单一色占比 ≤ 40%（防死分支与塌缩）；
3. **反向对照**：漂移取色、塌缩取色、缺一套色三种坏实现**必须被判失败** ——
   否则上面第 2 条判据没有判别力。

> ⚠️ **别用 `hashWord` 直算来测「稳定性」。** 拿一个纯函数与它自己比较恒为真，
> 选色逻辑整个塌缩（例如 `auto` 永远返回第一套色）它照样报绿 —— 那是假测试。
> 已经踩过一次：换成走真实选色路径后，两条篡改（塌缩 / 漂移）才被分别抓出。
