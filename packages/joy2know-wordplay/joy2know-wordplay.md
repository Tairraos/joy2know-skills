### 5.1 本轮查出的真缺陷：一条**恒真用例**（假测试形态）

`selftest` 里原来那条「配色哈希稳定」是这么写的：

```js
for (let i = 0; i < 8; i++) {
  const k = PALETTE_NAMES[(hashWord('甲方') % PALETTE_NAMES.length)];
  if (k === PALETTE_NAMES[(hashWord('甲方') % PALETTE_NAMES.length)]) n++;
}
```

`===` 两边是**同一个纯表达式**，`n` 恒为 8 —— **这条用例永远不可能失败**；
而且它压根没调用真正的选色函数 `resolvePalette`，所以**选色逻辑整个坏掉它也照样报绿**。

**已修**：换成走**真实选色路径**的两条判据（60 词逐词取两次须一致；8 套色全可达且单一色
占比 ≤ 40%），并补 3 条**反向对照**证明这两条判据有判别力。

## 六、未覆盖项 / 已知缺陷 / 待办

**未覆盖项（本条不为空，符合纪律要求；下次检测优先消掉）：**

1. **触发层路由未实测**：`description` 里声明的触发词（别解 / 汉语新解 / 名词解释 / 幽默词典 …）
   与「不适用于」场景（正经词典释义、词源考证、需要真实数据的图表、海报与 UI 设计稿、
   把词条翻译成其它语言）属 AI 触发路由，本机无触发环境，**未在真实触发链路里验证
   「该触发的触发、不该触发的不触发」**。
2. **别解写作品质无法机器判定**：本包最核心的验收标准是「读完会咯噔一下、再看图明白为什么成立」，
   以及「不是同义改写」「事实有出处」。这些是**写作判据**，脚本只能查卡片形态，**查不了这句话
   写得对不对、有没有编事实**。本轮**未做**人工盲评（例如拿 20 个词请人打分）。
3. **§九 人工降级路径未实测**：声明「跑不了脚本时手写 SVG 并人工核对、且须告知用户未过 check」
   属 AI 行为，无脚本可跑；本包脚本纯内置模块、无外部依赖，**不存在「藏起依赖就降级」的
   脚本级降级路径**可供复测。
4. **`check` 的颜色去重是字面比对**：`#FF0000` 与 `#ff0000` 会被算作两色（报错时统一转小写显示）。
   当前 8 套配色全用大写十六进制，正常路径不受影响；**未实测**「允许手写片段用 `rgb()` /
   简写 `#f00`」后的合并计数是否正确 —— 这是本报告 §四 标注的「一处需观察」。
5. **`selftest` 的分散度阈值 40% 未经多批次校准**：它是在**一组固定 60 词**上验的
   （实测极值 11/60 ≈ 18%）。若将来把 `SAMPLE_WORDS` 换掉，需重新确认阈值仍不误报 ——
   **本轮只验了「换掉会怎样」里的『不许缩减』这一面，未做「换一批词仍不误报」的实验**。
6. **`--palette random` 只验证了「能用」**：未测多次调用后的分布是否均匀（真随机的均匀性
   不是本包承诺，故未投入）。
