# 头像提示词参考

> 给 `joy2know-asset-smith` 在做图标时取用。**两条路线各有一套物料，别混用。**

---

## 一、先问用户（必问）

> 这个头像你想**自己生成**，还是**让 WorkBuddy 画**？

| 用户选 | 给他什么 |
|---|---|
| **自己生成** | 路线 A 的**可粘贴提示词** |
| **让 WorkBuddy 生成** | 路线 B 的**3/4 提示词 + 裁切步骤** |

⚠️ **不要默认**。两条路的物料不同，给错了用户白折腾一轮。

---

## 二、三要素怎么定（两条路线共用）

按**这个专家的功能**定三件事。下表是**启发式默认值**，**必须能被用户一句话推翻**。

| 领域 | 性别默认 | 专业服装 | 专业道具 |
|---|---|---|---|
| 技术 / 工程 / 安全 | 男 | 深色衬衫或工装马甲 | 笔记本电脑、扳手、示波器 |
| 数据 / 分析 / 金融 | 男 | 素色西装衬衫（不打领带） | 报表、计算器、图表 |
| 医疗 / 健康 | 不限（多取女） | 白大褂 | 听诊器、病历夹 |
| 法律 / 合规 | 男 | 正装西装 | 法典、卷宗 |
| 教育 / 培训 | 不限（多取女） | 针织衫或衬衫 | 书本、粉笔、教鞭 |
| 内容 / 文案 / 创作 | 不限（多取女） | 休闲创意装 | 钢笔、稿纸、键盘 |
| 设计 / 视觉 | 不限 | 简约黑或素色上衣 | 数位板、色卡、画笔 |
| 运营 / 增长 / 市场 | 不限（多取女） | 商务休闲 | 数据看板、放大镜 |
| 客户服务 / 行政 | 女 | 制服或商务休闲 | 耳机、日程本 |
| 研究 / 学术 | 不限 | 学者装（毛衣 + 衬衫） | 显微镜、论文、书堆 |

**怎么用**：
1. 按领域取一行，把三要素填进下面的模板；
2. 给完补一句 **「性别 / 服装 / 道具是我按 <领域> 选的，任一条要改直接说」**；
3. 用户说了就改，**不要争**。

> ⚠️ 这张表是**启发式，不是规定**。它只负责「给一个不用用户想太多的默认」，
> 真正的决定权在用户。**领域对不上时，问一句「你想让它像什么样的人」比硬套表格好。**

## 三、路线 A · 给用户自己生成的提示词

### 模板（照抄，只替换 `<>` 里的内容）

```
一个 <> 性别的 2.5D 头像，半身，头部较大的可爱造型，非写实，成年亚洲面孔，
穿着 <专业服装>，手里或身旁有 <专业道具>，
面向正面偏侧，表情 <专业且亲切 / 冷静专注>，柔和的正面光，
干净的纯色或浅渐变背景，构图居中，上下左右留出适当边距，方形 1:1
```

### 有参考图时，追加一句

```
脸型参照我提供的参考图。
```

### 输出格式要求

给用户的必须是**一整段可直接粘贴的提示词**，后面**另起一行**给出说明：

> 性别 / 服装 / 道具是我按 <领域> 选的 —— 任一条要改直接说。

**不要把提示词拆成散点让用户自己拼**，也不要只描述风格而不给完整句。

## 四、路线 B · 让 WorkBuddy 生成（3/4 + 裁切）

### 必须先告知两件事

1. **WorkBuddy 生成的图右下角带水印**；
2. **可以提供参考图**（作用同路线 A）。

### ① 生成 3/4 比例的竖版图

**比例 ≈ 3:4**（如 768×1024 / 900×1200）。

提示词模板：

```
一个 <> 性别的 2.5D 头像，非写实，成年亚洲面孔，穿着 <专业服装>，
手里或身旁有 <专业道具>，柔和的正面光，干净的浅色背景。

构图要求（重要）：
- 画布比例 3:4 的竖版
- 画面上方留白约 1/8，下方留白约 1/8
- 头像主体画在中间的方形区域内，不要贴近画布边缘
- 中间方形区域之外保持纯色空白
```

### ② 裁切

```bash
python3 scripts/crop-avatar.py <生成的图> <输出.png>
```

脚本做三件事：**居中取正方形 → LANCZOS 缩到 512×512 → 自检尺寸与体积（≤500KB）**。

可选参数：
- `--side-ratio 0.9` —— 方形只取整宽的 90%，**再往里收一点**；
- `--no-resize` —— 只裁切不缩放，用来先看效果。

### ③ 为什么这样做（**别省这段解释**）

水印在**右下角** → 上下留白把它顶进**下方空白区** →
居中裁出中间方形时，水印**一起被切掉**，得到干净方图。

> 所以「3/4 比例 + 上下留白」是**为了躲水印**的工程要求，**不是审美偏好**。
> 少了任何一条（比如画成 1:1、或头像撑满整张），水印就会留在成品里。

### ④ 收尾自检

裁完**亲眼看一遍**：
- ⚠️ **头像被切到下巴或额头** → 说明生成时留白不够，**回去重新生成，不要硬裁**；
- ⚠️ **成品里还能看到水印残留** → 同样重新生成（把留白写得更明确）。

## 五、常见坑

| 症状 | 原因 | 处理 |
|---|---|---|
| 成品右下角有水印 | 生成时没按 3:4 + 上下留白，或头像撑满画布 | 重新生成，把构图要求原样放进提示词 |
| 裁完切到下巴 / 额头 | 头像主体太靠边，或留白不足 | 重新生成；临时可用 `--side-ratio 0.9` 收一收 |
| 尺寸不是 512×512 | 用了 `--no-resize` | 去掉该参数重跑 |
| 体积超 500KB | 输出是未压缩的 PNG | 平台上限就是 500KB；换背景更简单，或压一次 PNG |
| `sips` 路径报「只支持 PNG」 | 输入是 JPG 且本机没有 Pillow | `pip install Pillow`，或先把图转成 PNG |

**规格（平台口径，别猜）**：**512×512px、≤500KB、JPG/PNG**。
