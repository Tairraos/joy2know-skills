# 运营数据读法与分析方法

> 给 `joy2know-asset-insight` 取用。**所有内容来自 2026-10-13 的真实调用**。
> 平台没有公开文档，这份是逐项核对平台「运营数据」页面整理出来的。

---

## 一、数据从哪来（**页面取，不调接口**）

**本参考只讲怎么读数据，不讲怎么取数据。**

在开放平台打开 **「运营数据」**（左侧菜单，路径 `/operations`）：

| 页面元素 | 用途 |
|---|---|
| **时间范围** | 切近 7 / 30 / 90 天 —— **三档都看**，单档看不出斜率 |
| **资产类型** | 技能 / 专家分开看，两类量级差很多 |
| **具体资产** | 可单独盯一个资产看它的日曲线 |
| **表格列** | 资产 · 安装量 · 调用量 · 活跃用户 · 人均使用频次 · 次周留存 |

把表格读出来（或截图）交给分析即可。

> ⚠️ **为什么本技能不代取数**：平台要求开发者**不得超出用户、平台或第三方授权调用接口、
> 执行代码或开展自动化任务**。原先随包的取数脚本**已删除**——
> 它的代价是整个技能过不了审，而**分析方法本身不受影响**。

## 二、字段与状态怎么读（页面上的数字也有"不可用"态）

页面上你会遇到三种数字，**别把「—」当 0**：

| 页面显示 | 含义 | 处理 |
|---|---|---|
| 正常数字 | 已算出 | 直接用 |
| **`—` / 空白** | 该指标对这条资产**不适用**，或平台未下发 | **排除**，别当 0 参与均值 |
| **`0`** | 真的没有 | 正常计 0 |

⚠️ 实测 **「错误率」长期为空**（平台未下发）—— **任何基于它的结论都是编的**，不要用。


## 三、指标读法

| 指标 | 单位 | 读法 | 陷阱 |
|---|---|---|---|
| `installs` | 次 | 入口热度 | 装得多不代表在用 |
| `calls` | 次 | **使用强度的主排序依据** | — |
| `activeUsers` | 人 | 覆盖面 | ⚠️ **各资产独立去重，跨资产相加会重复计人** |
| `frequency` | 次/人 | ≥3 算形成习惯；≈1 是「试一下就走」 | 分母是 activeUsers，样本小时波动大 |
| `weekRetention` | 0~1 | 下周还回来的比例 | 多数资产为 0，见下 |
| `errorRate` | — | **本次实测恒为 `na`** | 不要用 |

## 四、四把尺子（固定分析顺序）

### 尺子 1 · 集中度

```
Top3 调用 / 全站调用
```

- **> 70%** → 头部集中，**资源压头部**，长尾不要平均用力
- **30%~70%** → 相对分散
- **< 30%** → 没有明显赢家，值得做形态复盘

### 尺子 2 · 粘性

```
calls ÷ installs        （每个安装被调用了多少次）
```

| 区间 | 含义 |
|---|---|
| **> 3** | 强粘性 —— 用户主动回来用 |
| 1.5 ~ 3 | 正常 |
| **≈ 1** | 「装了就试一次」，体验或引导有问题 |

**安装高 + 粘性低 = 装了不用**。数据只能**指出位置**，
**为什么不用要去查首次使用流程** —— 不要从数据直接编原因。

### 尺子 3 · 留存

统计 `weekRetention > 0` 的资产个数：

- **全站为 0** → 问题**不在单个资产**，在「首次使用没形成习惯钩子」，这是结构性问题
- **个别非零** → 去看那几个做对了什么（它们的首次体验有什么不同）

### 尺子 4 · 加速

```
近 7 天调用 ÷ 30 天调用
```

| 区间 | 含义 |
|---|---|
| **≥ 40%** | 近期在加速 |
| 10% ~ 40% | 平稳 |
| **< 10%** | 热度已过去（30 天前火过） |

⚠️ **样本 < 5 次调用不要算比例** —— 分母太小，1 次变 2 次就是 100%。

## 五、报告口径（每条都要写进报告）

1. **只看有数据的资产**：页面上**只列有访问记录的资产**。没出现 ≠ 表现差。
2. **日序列有跳日**：平台只在有活动时落点。「有效天数」要用 **调用 > 0 的天数**，不能用 `daily.length` 直接当满窗。
3. **活跃用户不可跨资产相加**（去重口径不同）。
4. **三档窗口一起拉**：7 / 30 / 90 天。单窗口看不出斜率。
5. **样本太小的要明说**：装 1 次、调 2 次的资产必须标「样本不足，需再观察」，**不能据此判死刑**。
6. **不做平台未开的维度**：来源渠道、地域、机型 —— 没有就是没有，**不推测**。
