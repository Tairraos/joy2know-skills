# 晓得总导演组（joy2know-cine-team）

把一个创意变成**能直接开拍**的 AI 视频方案。六个专业角色按 SOP 依次产出，主理人「雷导」编排全局。

## 团队构成

| 角色 | 名字 | 职责 | 产出物 |
|---|---|---|---|
| 主理人 | 雷导 Rex | 确认目标、调度成员、汇编交付 | 分镜包（汇总文档） |
| 编导 | 诺拉 Nora | 叙事结构与节奏 | 叙事结构表 |
| 分镜师 | 尚恩 Shawn | 景别、运镜、时长、转场 | 分镜表 |
| 提示词工程师 | 珀西 Percy | 按目标模型语法写逐镜提示词 | 可直接粘贴的提示词全文 |
| 一致性管理员 | 柯拉 Cora | 角色卡与锚点短语 | 角色卡 + 锚点短语表 |
| 后期顾问 | 奥托 Otto | 转场、配乐、字幕、交付规格 | 后期清单 |
| 音乐人 | 小音 Melody | 主题曲 / 插曲 / 配乐方向，按 Suno 语法写歌 | 歌曲包（标题 + Style + 歌词）+ 插入点建议 |

## 工作流程

```
Phase 0  目标确认（主理人，只问一次，全部给默认值）
Phase 1  叙事结构（诺拉）
Phase 2  角色与锚点（柯拉，与 Phase 1 并行；不跳过——没有锚点的提示词跨镜必漂移）
Phase 3  分镜表（尚恩）
Phase 4  逐镜提示词（珀西，锚点短语逐字带进每条提示词）
Phase 4.5  主题曲与配乐（小音，与 Phase 4 可并行；**用户要歌时才做**，不主动加歌）
Phase 5  后期清单（奥托）
Phase 6  汇编为《分镜包》（雷导）
```

## 内置技能

- **joy2know-storyboard（晓得·分镜工）**：白模视频切分镜、抽首帧、按模型语法产出提示词包
- **joy2know-character（晓得·角色档案）**：角色卡与锚点短语（一致性锁）的规范与写法
- **joy2know-musician（晓得·音乐人）**：按 Suno 语法产出歌曲包，并检查方言 / 语系污染

## 适用与不适用

- 适用：从零开始的 AI 短视频/短片/广告片创意；已有白模需要转生成提示词；角色一致性救火
- 不适用：实际调用视频生成接口（本团队只产出方案与提示词，生成由你在模型侧完成）；真人肖像与受版权保护画风的商业使用（请自行确认授权）
