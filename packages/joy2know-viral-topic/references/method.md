# 选题炼法 · 判据细则

本文件是 `SKILL.md` 里四张表的展开：**心法怎么判、维度怎么给分、什么算虚高**。SKILL.md 给流程，这里给边界。

---

## 一、12 条心法的判定边界

亮灯的三种状态含义固定：**✅ 过**（没有争议）/ **⚠️ 勉强**（现在过，但要盯住）/ **❌ 不过**。

### 红线 7 条（命中 1 条 → 淘汰该方向）

**① 人群明确**
- 过的样子：说得出「给谁看」，且这个人在脑子里有具体形象（「厂里负责安全台账的那个人」「刚生完孩子、每天睡不到五小时的人」）。
- 常见误判：把「关注健康的人」当人群 —— 这是需求的同义反复，不是人群。
- 自检问句：**把这句话念给一个陌生人听，他能画出一个人来吗？**

**② 卖点承载**
- 过的样子：内容本身就在证明卖点（讲「一趟查完 80 项」这件事，本身就是「省往返」的证据）。
- 常见误判：把「顺便提一句产品名」当作承载。硬贴的标志是 —— **把产品名抠掉，这条内容讲的事就完全不成立了**。
- 自检问句：**这条内容，能不能不加产品名也照样讲圆？** 能，说明它不承载卖点。

**③ 角度不撞车**
- 过的样子：要么同类没认真讲过，要么同样的题我们能讲出明显新的部分（新数据、新场景、新对象）。
- 常见误判：把「换个说法讲同一个道理」当作新角度。说法新不算角度新。
- 自检问句：**同类最火的那条已经这么讲了吗？** 是 → 不过。

**④ 单点清晰**
- 过的样子：说得出六个字以内的主题（「三种算法」不算，它有三个点；「检测别漏项」可以）。
- 常见误判：把「有主线的一篇长文」当单点。单点指的是**一个主张**，不是一篇文章。
- 自检问句：**这条最想让读者记住的那一句是什么？** 答不出来或答出三句 → 不过。

**⑤ 真实可信**
- 过的样子：每个数字、每个因果都指得出来源；不出现绝对化用词。
- 常见误判：把「普遍认为」「业内都知道」当作来源。这是无主语的断言。
- 自检问句：**这条里的每个事实，删掉还是留？** 删不掉又指不出来源的，删。

**⑥ 合规安全**
- 过的样子：不涉政敏、不站队、不诱导分享；出现真人肖像有授权；出现品牌名有授权。
- 常见误判：把「大家都这么发」当作合规依据。
- 自检问句：**这条被举报一次，我能不能说清依据？**

**⑦ 不违背定位**
- 过的样子：落在既定定位与卖点范围内。
- 特殊情形：一个特别火但无关的话题 —— **不要偷偷塞进池子**，写进「池外建议」并说明它与定位的关系，由人来决定要不要为它调整定位。

### 黄线 5 条（命中 ≥2 条 → 返工）

**⑧ 平台适配**、**⑨ 转化承接**、**⑩ 可复用**、**⑪ 信源可溯**、**⑫ 时效判断** —— 这五条不影响"做不做"，影响"做完能跑多远"。命中两条以上，说明这批选题整体偏弱，重做一轮比硬做划算。

## 二、8 维打分的完整锚点

1–5 分，**只允许给整数**。给分时必须写一句依据，写不出依据的分数一律按 3 分算。

### ① 情绪强度

| 分 | 锚点 |
|---|---|
| 1 | 纯信息陈述，读完没有情绪起伏 |
| 2 | 有一点情绪，但需要读者自己代入才出现 |
| 3 | 有明确情绪，但不够疼（读者会点头，不会皱眉） |
| 4 | 情绪明确且具体，能让人停顿 |
| 5 | 一秒戳中（读者看到第一句就知道"这说的是我"） |

**虚高信号**：给 5 分却只能说出「挺有共鸣的」—— 共鸣是３分档的词。

### ② 传播动机

| 分 | 锚点 |
|---|---|
| 1 | 看完划走，没有任何动作冲动 |
| 2 | 可能收藏，但不会转 |
| 3 | 想点个赞（认同，但不涉及别人） |
| 4 | 想转发到某个群里 |
| 5 | 想立刻转给某一个具体的人（"这个你得看看"） |

**虚高信号**：把"有用"当"想转"。有用是收藏动机，不是转发动机。

### ③ 角度独家性

| 分 | 锚点 |
|---|---|
| 1 | 全网都在说，且我们说得并不比人好 |
| 2 | 全网都在说，但我们有一个细节比别人实 |
| 3 | 角度略新：同类讲过相邻的，没讲这个 |
| 4 | 少见：搜同类关键词翻两页翻不到 |
| 5 | 没见别人这么讲过，且讲了别人也很难抄（因为它依赖我们的独家事实或数据） |

**虚高信号**：把「我们第一次讲」当「没人讲过」。前者是我们自己的历史，后者是市场事实，需要证据。

### ④ 人群匹配

| 分 | 锚点 |
|---|---|
| 1 | 谁都能看（等于谁都不专） |
| 2 | 有一类人会看，但不确定是哪一类 |
| 3 | 目标人群里的一部分会停下来 |
| 4 | 目标人群里的大部分会停下来 |
| 5 | 精准戳中目标人群，且**非目标人群会觉得与自己无关** —— 后半个条件是关键 |

**虚高信号**：给 5 分但非目标人群也爱看。那说明它击中的是普适情绪，不是人群匹配。

### ⑤ 时效性

| 分 | 锚点 |
|---|---|
| 1 | 什么时候发都行（常青） |
| 2 | 与某个周期性节点相关（季度、年检、开学） |
| 3 | 蹭着当前的讨论热度 |
| 4 | 蹭着热点，且窗口期还有一周以上 |
| 5 | 不发就过期（窗口期以天计） |

**注意**：**常青选题不是低分选题。** 这条只衡量"借不借势"，不衡量好坏。给 1 分的常青题照样可以总分过线。

### ⑥ 卖点承载 ★

| 分 | 锚点 |
|---|---|
| 1 | 讲不出这条内容与产品的关系 |
| 2 | 关系要靠一段解释才能建立 |
| 3 | 能带上，但略生硬（读起来像植入） |
| 4 | 带得自然，是内容的一部分 |
| 5 | 内容本身就是卖点的证据（删掉卖点，这条内容就不成立） |

**虚高信号**：把"结尾加了一句产品介绍"当作承载。结尾硬加 = 3 分封顶。

### ⑦ 形态可行性

| 分 | 锚点 |
|---|---|
| 1 | 只能用文字干讲，做不出画面或场景 |
| 2 | 有画面感但需要大投入 |
| 3 | 可以做成图或短口播 |
| 4 | 一看就适合某个形态，且素材现成 |
| 5 | 形态呼之欲出（读完第一句就想到了怎么拍），且渲染成本低 |

### ⑧ 转化承接 ★

| 分 | 锚点 |
|---|---|
| 1 | 看完没有下一步可做 |
| 2 | 有下一步，但需要读者自己想到 |
| 3 | 有明确引导，但绕（要先加好友再说事） |
| 4 | 引导清楚，动作门槛低 |
| 5 | 看完自然知道该干什么，且这个动作**与内容本身是一件事**（不是外挂的广告） |

**虚高信号**：把"留了联系方式"当作转化承接。外挂的引导最多 3 分。

## 三、最常出现的三类虚高

1. **把"我觉得"当依据。** 每一维都要能指向一个具体事实或一个具体动作。指向不了 → 按 3 分算。
2. **整体调高。"** 这批都挺不错的" → 八维全 4 分 → 32 分 → 全是"合格"。**八维分数分布过于集中（方差极小）本身就是异常信号**，说明打分没有区分度，回炉重打。
3. **把 ⑥⑧ 当成"可以以后再说"。** 这两维是推广选题的命门。先按分数出池，再对 ⑥ 或 ⑧ 低于 3 分的条目单独看一遍 —— 脚本会把它们标出来。

## 四、形态适配检查

标出最佳形态之后，逐条核下面三件事，任一条不成立就换形态：

1. **平台吃不吃**：这个平台的头部内容里有没有同类形态？找不到先例的要说明理由，不要想当然。
2. **我们做不做得出来**：口播要有人出镜、剧情要有场景、混剪要有素材。做一个做不出来的形态，等于不做。
3. **形态与卖点冲不冲突**：长文适合讲因果，海报只装得下一句。**卖点需要的解释长度，不能超过形态能给的篇幅。**
