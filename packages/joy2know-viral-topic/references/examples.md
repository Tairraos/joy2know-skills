# 选题炼法 · 正反例对照

**没有对照，尺子就不成其为尺子。** 下面三条都是真跑过脚本的结果（命令写在每条末尾，可复制复核）。
读每一条时重点看两件事：**给分理由指向的是事实还是感觉**、**⑥⑧ 两维在做什么判断**。

---

## 例一 · 35 分 → 重点做（恰好压在阈值线上）

**推广对象**：某职业卫生技术服务（职业病危害因素定期检测）
**选题**：「一年一次的检测，最容易漏掉的三项 —— 附自查清单」

**心法亮灯**：12 条全 ✅

**基因命中 3 条**：信息差（行业内幕 + 反常识）、行动触发（清单可直接用）、身份标签（画像锚定到"负责台账的那个人"）

| 维度 | 分 | 依据 |
|---|---|---|
| ① 情绪强度 | 5 | "最容易漏掉"一秒戳中 —— 漏项是要担责的，不是泛泛的担心 |
| ② 传播动机 | 4 | 会转到同岗位的群里（"你也是管这个的吧"） |
| ③ 角度独家性 | 5 | 漏项数据来自我们自己的检测台账，同类讲不出 |
| ④ 人群匹配 | 5 | 负责台账的人必看；不负责的人完全不关心 —— 后半个条件成立 |
| ⑤ 时效性 | 2 | 常青，不借势（季度节点略相关，不强） |
| ⑥ **卖点承载** | 5 | "一次查全、不用来回补"的证据，就是这张清单本身 —— 删掉卖点这条内容不成立 |
| ⑦ 形态可行性 | 4 | 清单天然适合图文截图保存；素材（检测项目表）现成 |
| ⑧ **转化承接** | 5 | 结尾动作 = 领自查清单，与内容是一件事，门槛低 |
| **总分** | **35** | **重点做**（35 是这一档的下限 —— 再松任意一维就掉进「合格」） |

```bash
python3 scripts/score.py --dims 5,4,5,5,2,5,4,5 --genes 3
# → 总分 35/40 · 重点做；⑥5 ⑧5，无告警
```

**为什么它是推广选题而不是流量选题**：⑧ 的承接动作（领清单）**就是内容本身**，不是外挂的广告位。

## 例二 · 18 分 → 淘汰

**推广对象**：同上
**选题**：「我们公司完成年度团建，团队氛围超好」

| 维度 | 分 | 依据 |
|---|---|---|
| ① 情绪强度 | 1 | 纯陈述，读者无情绪 |
| ② 传播动机 | 1 | 没有人会转"别人公司的团建" |
| ③ 角度独家性 | 2 | 满屏都是，且我们写得并不比别人好 |
| ④ 人群匹配 | 1 | 只有本公司的人会看 → 等于没有目标人群 |
| ⑤ 时效性 | 3 | 蹭了当天的热度（时效是它唯一的得分项） |
| ⑥ **卖点承载** | 1 | 讲不出与检测服务的关系 |
| ⑦ 形态可行性 | 5 | 照片现成、拼图就能发 —— **形态容易做，不代表值得做** |
| ⑧ **转化承接** | 4 | 结尾引导本身是清楚的、门槛也低 —— 但这救不了它，见下 |
| **总分** | **18** | **淘汰** |

```bash
python3 scripts/score.py --dims 1,1,2,1,3,1,5,4
# → 总分 18/40 · 淘汰；⑥1 ⑧4 → 两处告警
```

**注意 ⑦ 拿了 5 分、⑧ 拿了 4 分，总分还是 18。** 「好做」和「承接还算清楚」都救不了一条**没人想看**的内容。
这条也提醒一件事：**⑧ 的分数不能脱离 ①②④ 单独看** —— 一条没人看的选题，结尾引导写得再顺也没意义。

## 例三 · 31 分 → 合格，但**必须按流量选题处理**

**推广对象**：一个面向家长的学习类小程序
**选题**：「开学第一周，孩子的这 3 个表现最容易被误判成懒」

**心法亮灯**：12 条全 ✅

**基因命中 4 条**：情绪钩子（焦虑 + 共鸣）、信息差（反常识）、身份标签（家长画像）、行动触发（判断方法）

| 维度 | 分 | 依据 |
|---|---|---|
| ① 情绪强度 | 5 | "被误判成懒"直接戳中家长的愧疚 |
| ② 传播动机 | 5 | 家长会立刻转给另一半或家长群 |
| ③ 角度独家性 | 4 | 反常识角度，同类少见 |
| ④ 人群匹配 | 5 | 有学龄孩子的家长必看 |
| ⑤ 时效性 | 5 | 开学季，两周内不发就过期 |
| ⑥ **卖点承载** | 2 | 前五维讲的是"孩子的行为"，与小程序的功能要靠一段解释才能接上 |
| ⑦ 形态可行性 | 4 | 适合短视频口播 + 图文两版 |
| ⑧ **转化承接** | 1 | 全文没有下一步 —— 家长看完只有焦虑，没有出口 |
| **总分** | **31** | **合格（但有告警）** |

```bash
python3 scripts/score.py --dims 5,5,4,5,5,2,4,1 --genes 4
# → 总分 31/40 · 合格
# → ⚠️ 流量选题告警：①–⑤ 均 ≥4，而 ⑥=2 ⑧=1
```

**这条是三种典型里最危险的一种**，因为它分数不低（31，落在"合格"档）、基因命中 4 条、时效性满分 —— 看起来完全该做。

但它的实质是：**用一条会爆的内容，把一批家长推到焦虑的顶点，然后没有出口。** 流量到手，人没留下。

**正确的处置不是砍掉它，是把它改成推广选题** —— 两个改法：

1. 补 ⑧：结尾给一个**与内容同构**的动作（"这三个表现的判断方法，我们做成了自查表"），⑧ 从 1 → 4，总分 34。
2. 补 ⑥：把"孩子的表现"换成"我们用哪三个观察点做判断"，卖点从植入变成内容本身，⑥ 从 2 → 4，总分 33。

两个都补 → 36 分，进"重点做"档。**同一个选题，改两处，从负资产变成主推** —— 这就是 ⑥⑧ 两维存在的全部理由。

## 一个反面对照：什么样的打分是无效的

| 现象 | 说明什么 |
|---|---|
| 八维全是 4 分（总分 32） | 打分没有区分度。八维分数方差过小是异常信号，回炉重打 |
| 每一维的依据写成"感觉不错""挺有意思" | 依据不指向事实 → 按 3 分算 |
| 总分 33，但 ⑥⑧ 是 2 和 1 | 分数只用来排序，**告警必须单独看** —— 脚本会把这两维标出来就是为此 |
| 先定"这条要做"，再倒着凑分数 | 这是打分卡最常见的失效方式。**顺序只能是先打分、后决定** |
