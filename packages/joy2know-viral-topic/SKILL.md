# 晓得 · 选题炼法

把「下周发什么」这件事，从凭感觉改成按判据筛、按维度打分。

## 一、先分清：它是什么，不是什么

| 它是什么 | 它不是什么 |
|---|---|
| **一把筛子** —— 判断一批候选该不该做、先做哪个 | **不是写手** —— 不产正文、不产成品标题 |
| **一张尺子** —— 同一条选题，谁打分都得到同一个分 | **不是算命** —— 不预测播放量、不承诺会爆 |
| **一道门禁** —— 不合格的原料在第一步就被退回 | **不是灵感库** —— 不靠"我再想想"出活 |

**最常被跳过的一步是原料体检。** 很多人拿来的所谓"选题"其实只是一个话题名（「做个 AI 相关的吧」），那不是选题，是方向。本技能的第一步就是拦下这类原料退回补齐，而不是硬炼。

**没有卖点承载的爆款，在推广里是负资产。** 它花掉了预算，换来一批不会留下的人。所以 ⑥卖点承载 与 ⑧转化承接 是本技能的第六、第八维，也是它与「纯流量选题法」唯一的分界线。

## 二、工作流（四步，不许跳步）

```
① 原料体检 —— 12 条心法逐条亮 ✅ / ⚠️ / ❌
        │
        ├─ 红线命中 ≥ 1 条 → 停。退回补原料，不要往下炼
        ↓
② 匹配四大传播基因（每条候选至少命中 2 条）
        │
        ├─ 一条都没命中 → 砍掉，不论它多热点
        ↓
③ 8 维打分（交给脚本算，总分 40）
        ↓
④ 映射六大内容形态 → 出池（含 Top 3 + 淘汰区）
```

**②③ 之间不允许"感觉不错就跳过"。** 打分的价值不在于算出一个数字，而在于**同一个数字对不同人是一样的** —— 争「够不够爆」争不出结果，指分数可以。

## 三、12 条心法（生成候选之前逐条亮灯）

红线 7 条、黄线 5 条。**红线命中 1 条 → 直接淘汰该方向；黄线命中 ≥ 2 条 → 返工重来。**

| # | 心法 | 类型 | 判断标准 | 命中后果 |
|---|---|---|---|---|
| ① | 人群明确 | 🔴 | 一句话说得出「这条给谁看」，且那个人能想象出来 | 淘汰 |
| ② | 卖点承载 | 🔴 | 内容能自然带出至少一条核心卖点，不是硬贴 | 淘汰 |
| ③ | 角度不撞车 | 🔴 | 同类没认真讲过，或我们能讲出明显新的部分 | 淘汰 |
| ④ | 单点清晰 | 🔴 | 一条只讲一件事；说得出「六个字以内的主题」 | 淘汰 |
| ⑤ | 真实可信 | 🔴 | 不夸大、不编数据、不用绝对化用词 | 淘汰 |
| ⑥ | 合规安全 | 🔴 | 不涉政敏、不站队、不诱导分享、肖像有授权 | 淘汰 |
| ⑦ | 不违背定位 | 🔴 | 落在既定定位与卖点范围内，不漂移到无关话题 | 淘汰 |
| ⑧ | 平台适配 | 🟡 | 形态配得上平台（图文 / 口播 / 长文各有脾气） | 提示优化 |
| ⑨ | 转化承接 | 🟡 | 看完有下一步可做（关注 / 私信 / 预约 / 试用） | 提示优化 |
| ⑩ | 可复用 | 🟡 | 这类选题能重复做，不是一次性烟花 | 提示优化 |
| ⑪ | 信源可溯 | 🟡 | 引用的事实与数据都指得出来源 | 提示优化 |
| ⑫ | 时效判断 | 🟡 | 蹭热点的评估过窗口期；常青选题不受此限 | 提示优化 |

**亮灯不是打分。** 这一轮只输出 ✅（过）/ ⚠️（勉强）/ ❌（不过）与一句依据，**不要在这里给分数** —— 先筛掉不合格的，再给剩下的打分，两件事混在一起会让筛子失去作用。

细则（每条的判断边界、常见误判）见 `@references/method.md`。

## 四、四大传播基因（每条候选至少命中 2 条）

| 基因 | 它为什么管用 | 可用抓手 |
|---|---|---|
| **情绪钩子** | 人对情绪的反应快过对信息的反应 | 共鸣 / 愤怒 / 焦虑 / 惊讶 / 治愈 / 爽感 —— **一条最多用 1 个强情绪词，堆砌等于无效** |
| **信息差** | 「我知道你不知道」和「我得赶紧学」是两种最稳的点开动机 | 行业内幕 / 反常识 / 时效红利 |
| **身份标签** | 转发的本质是「我在表达我是谁」 | 画像锚定（越具体越好）/ 身份对立 / 替我发声 |
| **行动触发** | 「我马上能用」同时带来收藏与转发 | 工具型 / 方法型 / 避坑型 / 省钱省时 |

**命中 3 条以上 = 重点投入级。命中 0 条 = 砍掉，不论多热点。**

## 五、8 维打分卡（每项 1–5 分，总分 40）

**12 条心法全绿之后才进打分。**

| 维度 | 1 分 | 3 分 | 5 分 |
|---|---|---|---|
| ① 情绪强度 | 纯陈述，没情绪 | 有情绪但不痛 | 一秒戳中 |
| ② 传播动机 | 看完划走 | 想点个赞 | 想立刻转给某个人 |
| ③ 角度独家性 | 全网都在说 | 角度略新 | 没见别人这么讲过 |
| ④ 人群匹配 | 谁都能看 | 一部分人会停 | 精准戳中目标人群 |
| ⑤ 时效性 | 什么时候发都行 | 蹭着热点 | 不发就过期 |
| ⑥ **卖点承载** | 讲不出和产品的关系 | 能带上但略生硬 | 内容本身就是卖点的证据 |
| ⑦ 形态可行性 | 只能用文字干讲 | 可以做成图或短口播 | 一看就适合某个形态 |
| ⑧ **转化承接** | 看完没有下一步 | 有引导但绕 | 看完自然知道该干什么 |

**阈值（硬编码在脚本里，不要在对话中临时松绑）：**

| 总分 | 判定 |
|---|---|
| ≥ 35 | 重点做，配最好的人力与预算 |
| 30–34 | 合格，建议做 2 个变体 A/B |
| 24–29 | 边缘 —— 说清缺哪条、补得上就做 |
| < 24 | 淘汰 —— **不要因为「想凑够 10 条」而留下** |

**为什么 ⑥ 与 ⑧ 要单独标出来**：一条选题只有 ①–⑤ 高分、⑥⑧ 低分，那是**流量选题，不是推广选题**。脚本会对这个组合单独告警。

打分用脚本，别口算：

```bash
python3 scripts/score.py --dims 5,4,4,5,3,5,4,4          # 单条
python3 scripts/score.py --dims 5,4,3,5,2,5,4,4 --redlines 0 --genes 3   # 带心法 / 基因信息
python3 scripts/score.py --file 候选.json --json          # 批量，出机器可读结果
python3 scripts/score.py --selftest                       # 校验阈值与告警规则没被改坏
```

各维 1/3/5 分的完整锚点、以及「什么样的给分是虚高的」见 `@references/method.md`。

## 六、六大内容形态（选题要映射到形态）

| 形态 | 适合的选题特征 | 交给写手时要说清 |
|---|---|---|
| ① 短视频（口播 / 剧情 / 混剪） | 有前 3 秒能立住的冲突或反差 | 平台、时长、钩子方向 |
| ② 图文笔记（多图 + 短文案） | 有可被截图保存的清单、对比、步骤 | 图序结构、封面要点 |
| ③ 长文（公众号 / 知乎 / 官网） | 有纵深、可讲完整因果 | 读者是谁、读完要记住哪一句 |
| ④ 私域话术（社群 / 一对一 / 朋友圈） | 需要信任铺垫、针对老客或意向客 | 场景、语气、下一步动作 |
| ⑤ 海报与首屏（单图 + 一句话） | 一句话能说清、要在线下或落地页出现 | 字数上限、放在哪 |
| ⑥ 互动话题（评论区 / 投票 / 挑战） | 能引发表达欲、用户有话想说 | 抛出的问题、期望的回复方向 |

**一条选题可以适配多个形态，但必须标出一个"最佳形态"。** 标不出来的，回 ⑦ 形态可行性那条重打。

## 七、降级路径（原料不够时怎么走）

| 缺什么 | 怎么走 | 不许怎么走 |
|---|---|---|
| 给不出目标人群 | 用「三选一」逼出来：这条给三种人看，哪种最疼？ | 替他编一个人群（「年轻人」「有需求的人」不算人群） |
| 拿不到热点数据 | 改用不依赖数据的常青角度，并写「未获取到公开数据」 | 写「全网都在讨论」这类编的势能 |
| 只有一条候选 | 照样打分，但交付里必须写「单条样本，无横向比较」 | 给排名（只有一条还排什么名） |
| 一个卖点都说不出来 | 停。这不属选题问题，是定位问题，先补定位 | 硬贴一个卖点上去 |

|---|---|---|---|---|---|---|

## 三、Top 3 推荐

## 九、几条不能碰的线

1. **不编热点、不编数据。** 引用热点标时效（什么时候的事、窗口期还剩多久）；数据指出处；查不到就写「未获取到公开数据」并换角度。
2. **不写正文。** 本技能到「选题 + 标题方向 + 形态」为止。成品标题与脚本是写作环节的活。
3. **不因为「想凑数」而降低阈值。** 池子小不是问题，池子里混进不该做的才是问题。
4. **淘汰区不能空。** 一次交付里至少列 1–3 条被砍掉的选题与原因 —— 一个什么都没淘汰的选题池，说明筛子是摆设。
5. **分数不能手改。** 觉得脚本给的判定不对，改的是各维输入分（并说明为什么这一维该给更高），不是总分。
