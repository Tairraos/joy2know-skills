# 体裁配方：爵士 · 蓝调 · 民谣

> 三节共用一套结构：音乐外壳（token 模板）→ 结构与句式 → 歌词写法 → 正反例。
> 文风内核（写实动词 / 意象重组 / 矛盾修辞 / 韵脚分工）三条体裁通用，配方见 `@references/lyrics-craft.md`，此处不重复。

## 一、爵士 Jazz

**音乐外壳（token 模板）：**

```text
Jazz ballad, 72 BPM, smoky female vocal, upright bass + brushed drums + grand piano,
smoky and tender, empty bar after closing, close-mic warmth
```

| 项 | 取值区间 | 说明 |
|---|---|---|
| BPM | ballad 60–80 / 标准 90–130 / swing 130–160 | 慢歌先定 ballad，别写「慢爵士」 |
| 乐器盘 | 钢琴三重奏（piano + upright bass + brushed drums）、萨克斯、颤音琴、爵士吉他 | 鼓写 `brushed drums`（刷鼓）比 `jazz drums` 稳 |
| 人声质感 | `smoky` / `silky` / `velvety` / `half-spoken` | 爵士人声常带半说半唱，可写进段落标签 |
| 混音 | `close-mic warmth` / `smoky club ambience` | 复古质感可用 `warm analog` |

**结构：** AABA（32 小节标准曲式）或 verse-chorus。段落标签里留「乐器回答位」：

```text
[Verse 1 – Half-spoken, intimate, brushes only]
[Chorus – Legit singing, piano answers between lines]
[Bridge – Key shift, sax takes the lead for two lines]
[Outro – Rubato, bass walks down alone]
```

**歌词写法：** 爵士句宜短、留白多，适合「说一半」的口语感（「咖啡凉了一半 / 话也只剩一半」这类对仗）。
意象重组与矛盾修辞在爵士里最出彩（「热闹的荒凉」）。

**反例：** ✗ 爵士歌写密集长句排比——爵士的呼吸感来自留白；✗ 写 `epic orchestral`——与爵士 club 质感打架。

## 二、蓝调 Blues

**音乐外壳（token 模板）：**

```text
Slow blues, 72 BPM, gritty male vocal, electric guitar + harmonica + blues piano,
bittersweet and raw, midnight crossroads, vintage tube amp warmth
```

| 项 | 取值区间 | 说明 |
|---|---|---|
| BPM | slow blues 60–90 / shuffle 100–120 | shuffle 记得写 `shuffle feel, swung drums` |
| 乐器盘 | 电吉他（`electric guitar with slide`）、口琴、布鲁斯钢琴、低音提琴 | 失真克制：`vintage tube amp warmth`，别写 `distorted`（见反模式） |
| 人声质感 | `gritty` / `raspy` / `raw` / `wailing` | 蓝调人声可破，写 `raw` 就够，不要写 `screaming` |
| 混音 | `vintage tube amp warmth` / `live room sound` | — |

**结构：** 12 小节循环。歌词用 **AAB 句式**——第一句说一遍，第二句原样或微调再说一遍，第三句收底：

```text
[Verse 1 – Gritty, behind the beat]
凌晨两点的站台　风把灯吹得直晃
凌晨两点的站台　风把灯吹得直晃
我把没说的话　都咽成了烟
```

> AAB 的「重复句」直接把第一句抄第二遍——这正是 SKILL.md 规则 3「重复位置显式写」在蓝调里的自然形态。
> 第二段起可写 `[Verse 2 – Same AAB form, new imagery]`。

**歌词写法：** 蓝调自带的「重复 + 收底」结构是它的叙事引擎：前两句铺场景、第三句给那一记重的。
文风内核的「矛盾修辞」在这里变成「咽成烟」「笑着的疤」这类带痛感的收底句。

**反例：** ✗ 蓝调词写治愈明亮大团圆——调性自相矛盾，模型会各执行一半；✗ `distorted` + 大量爆破音字——
高频冲突易出破音，要颗粒感用 `gritty` / `raw` / `vintage tube amp warmth`。

## 三、民谣 Folk

**音乐外壳（token 模板）：**

```text
Acoustic indie folk, 82 BPM, soft female vocal, fingerpicked guitar + light strings + soft tambourine,
warm and nostalgic, morning train window, intimate room reverb
```

| 项 | 取值区间 | 说明 |
|---|---|---|
| BPM | 70–100 | 默认 80 上下 |
| 乐器盘 | 木吉他指弹（`fingerpicked guitar`）、口琴、轻弦乐、软打击乐 | 指弹写演奏法 `fingerpicked`，不写「木吉他伴奏」 |
| 人声质感 | `soft` / `breathy` / `clear` / `storytelling` | 民谣人声贴话筒，可写 `close-mic` |
| 混音 | `intimate room reverb` / `morning-light warmth` | — |

**结构：** 叙事主歌推进（两段主歌讲一个有前后的小故事），副歌收拢点题；bridge 放一把（抽掉打击乐）。
段落标签示例：

```text
[Intro – Fingerpicked guitar, distant rain]
[Verse 1 – Storytelling, close-mic]
[Chorus – Open vowels, layered vocals]
[Verse 2 – Same tempo, scene moves forward]
[Bridge – No percussion, bare vocals]
[Chorus – Repeat with last line changed]
[Outro – Fade out, guitar alone]
```

**歌词写法：** 民谣是三大体裁里最吃「写实动词 + 生活细节」的——治理配方三套预设（晨光 / 夜灯 / 归途）
全按民谣外壳标定，直接取用（`@references/lyrics-craft.md` 第四节）。韵脚分工（主歌闭口、副歌开口）在民谣里最严格。

**反例：** ✗ 民谣里堆 `epic` `cinematic` `orchestral`——编制爆炸就不是民谣了；✗ 副歌也闭口韵——唱不上去。

## 四、三体裁通用反模式

| 反模式 | 为什么不行 |
|---|---|
| 曲风词互相打架（`healing jazz blues` 带 grit 人声） | 情绪与人声质感冲突，模型各执行一半 |
| BPM 省略或写宽区间 | 三个体裁的速度就是它们的身份，速度漂了体裁就漂了 |
| 副歌写满不留白 | 爵士要呼吸、蓝调要留重复位、民谣要留一句给呼吸 |
| 乐器盘堆到六七件 | 三大体裁都是小编制美学；堆乐器是流行/管弦的写法 |
| 用中文写体裁词（「爵士一点」「蓝调感觉」） | token 用英文写到具体演奏法（`swung drums` / `slide guitar`）才可控 |
