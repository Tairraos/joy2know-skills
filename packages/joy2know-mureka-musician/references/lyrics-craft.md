# 治愈文风内核与中文歌词写法

## 一、为什么默认治愈

用户只说「写首歌」时，最容易翻车的是风格选择瘫痪——你给一堆选项，他一个都不满意。
治愈是最大公约数：接受面广、不容易出错、也最容易做出画面感。本技能的默认落点是**治愈系民谣**
（民谣是三大体裁里最承接治愈文风的壳）。
**默认治愈不等于只能治愈。** 用户指定爵士 / 蓝调等其他体裁时，音乐外壳与体裁句式全换，只保留下面的文风内核。

## 二、文风内核（换体裁也不换这一层）

| 技法 | 做法 | 例子 |
|---|---|---|
| **主歌写实** | 用具体动词代替抒情，靠生活细节铺陈 | 「锅铲刮过锅底 / 是这十年最安稳的闹钟」 |
| **意象重组** | 具象名词 + 抽象动词 | 「思念生锈」「黄昏结痂」「孤独发霉」 |
| **副歌张力** | 矛盾修辞 | 「拥挤的孤独」「热闹的荒凉」「最温柔的伤口」 |
| **语气助推** | 语气词增加倾诉感，一句一个 | 「呢」「吧」「啊」慎用 |
| **韵脚分工** | 主歌闭口韵（细腻），副歌开口韵（高亢） | 主歌押 i/ü/en，副歌押 a/ang/ao |

蓝调的 AAB 收底句、爵士的半说半唱，都是这套内核在体裁里的变体——见 `@references/genre-cookbook.md` 对应节。

## 三、中文歌词补断句细则（SKILL.md 规则 3 的展开）

「中文咬字糊」多数不是曲风问题，是歌词栏没给结构。四项必做：

1. **语言声明句**写在歌词栏最前：「全部使用简体中文，不要夹杂英文词，不要把拼音写进去。」
2. **段落标签显式写**：每段前 `[Verse 1]` / `[Chorus – 开阔，开口韵]`。复合标签（段落名 + 编曲描述）
   保留到英文部分，中文注释写在破折号后也可以（如 `[Chorus – 开阔，开口韵]`）；
   ⚠️ 若试听发现中文标签被当成歌词唱出来，退成纯英文标签。
3. **重复位置显式写**：第二遍副歌写 `[Chorus – 重复上面的副歌，末句改成「……」]` 或原文照抄。
   蓝调 AAB 的重复句直接抄两遍（见 `@references/genre-cookbook.md` 第二节）。
4. **行与断句**：每段 4–6 行；一行不超过一口气；靠标点自然断句，避免一行塞满不加停顿的长句。

## 四、三套预设（用户说「你看着办」时挑一套）

**A. 晨光** —— 醒来、和解、重新开始
- 意象：窗帘缝的光、凉掉的水、叠好的衣服
- 风格栏起手：`Acoustic indie folk, 78 BPM, breathy female vocal, fingerpicked guitar + warm piano, healing and hopeful, morning light through curtains, intimate room reverb`

**B. 夜灯** —— 独处、想念、与自己和解
- 意象：台灯、冰箱的嗡鸣、凌晨三点的窗
- 风格栏起手：`Mandarin folk ballad, 72 BPM, soft female vocal, piano + light strings + soft pads, intimate and melancholic but warm, lamp-lit desk at 3 am, close-mic warmth`
- 想要爵士底色：曲风换 `jazz ballad`、乐器盘换 `upright bass + brushed drums + piano`

**C. 归途** —— 回家、父亲母亲、旧物
- 意象：旧皮鞋、站台、行李箱的轮子声
- 风格栏起手：`Acoustic folk, 80 BPM, warm male vocal, fingerpicked guitar + harmonica + light percussion, nostalgic and gentle storytelling, hometown train platform, warm room sound`
- 想要蓝调底色：曲风换 `folk blues`、加 `bluesy guitar licks`（收底句改用 AAB 式）

三套的**意象清单是歌词素材**——只能写进歌词栏；纯器乐包要把意象翻译成乐器与织体的选择，不是写进方括号外面。

## 五、歌词栏完整示例（有人声包）

```text
全部使用简体中文，不要夹杂英文词，不要把拼音写进去。

[Intro – 安静的吉他，远处雨声]
[Verse 1 – 半念半唱，贴近话筒]
锅铲刮过锅底的声响
是这十年最安稳的闹钟
你走以后我学会
把孤单煮成两个人份的汤

[Pre-Chorus – 渐强，弦乐轻进]
有些话没说
就长成了年轮

[Chorus – 开阔，开口韵，层叠人声]
原来最拥挤的
是深夜里没有人的巷
温柔地告别
比相爱更需要胆量

[Verse 2 – 同 Verse 1 语气，换场景词]
阳台上的绿萝又黄了一片
像我总也学不会的放下

[Chorus – 重复上面的副歌，末句改成「比相爱更勇敢」]
[Bridge – 仅钢琴，放慢]
如果时间肯回头
我只想多坐一会儿
不说话
[Chorus – 重复上面的副歌]
[Outro – 渐弱，只剩吉他]
比相爱更勇敢
```

## 六、反例

| 反例 | 为什么不行 |
|---|---|
| 「我好想你 / 我真的好想你」 | 纯抒情无画面，模型唱不出层次 |
| 副歌押闭口韵 | 开口度不够，情绪顶不上去 |
| 全篇一种唱法 | 没有起伏，听感平；段落标签里至少分出「贴近」与「开阔」两档 |
| 治愈歌里加 `distorted` `bitcrushed` | 与治愈质感直接冲突（蓝调要颗粒用 `gritty` / `raw`，见体裁配方） |
| 意象全是「星星、月亮、大海」 | 空泛，换成用户身边能摸到的东西；编不出就用三套预设的意象清单 |
| 每段都写满 | 留白是治愈的一部分，主歌留一句空白给呼吸 |
| 两遍副歌内容不同又不标注 | 模型猜不到你想怎么变，会各唱各的 |
