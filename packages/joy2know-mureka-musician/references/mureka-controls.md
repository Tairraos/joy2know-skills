# Mureka 界面控件与 FAQ 实测

## 一、控件全表（自定义模式，实测）

| 控件 | 位置 | 取值 / 上限（实测） | 怎么用 |
|---|---|---|---|
| **歌词栏** | 自定义模式主输入 | **≤5000 字** | 放语言声明 + 中文歌词 + 段落标签 |
| **纯音乐** | 歌词栏右上开关 | 开 / 关 | **打开 = 器乐**，歌词栏留空或只留标签 |
| **风格栏** | 歌词栏右侧 | **≤1000 字** | 英文 token 七要素（见 `@references/style-tokens.md`） |
| **人声性别** | 独立一行 | 女声 / 男声 | 与风格栏的 `female vocal` / `male vocal` 保持一致 |
| **歌名** | 独立输入框 | **≤50 字** | 可留空；中文标题直接写 |
| **参考歌曲**（Pro 能力） | 顶部 `+参考歌曲` | 上传音频 / 视频提取音频 | 传一段音频生成相似风格；**与「人声性别」冲突，见第二节** |
| **Remix** | 顶部 `+Remix` | 上传歌曲或哼唱旋律 | 保留旋律换风格重编；支持「哼唱旋律」提供自己的旋律 |
| **自定义歌手** | 顶部 `+自定义歌手` | 上传音频 / 粘贴链接 | 用固定的人声唱你的歌——**多首歌人声一致唯一可靠的做法** |
| **生成歌词 / 优化** | 歌词栏按钮 | — | 按主题起草 / 润色草稿；**草稿自己改**，别全托管 |
| **增强** | 风格栏按钮 | 润色丰富 / 换新方向 | ⚠️ **会改写你写好的风格栏文本**——要复现就别点 |

> ⚠️ **实测纠偏**：自定义面板里**没有**歌曲时长滑杆、**没有**生成版本数选择、**没有**音高 / 混响 / 咬字等人声参数。
> 一次生成出 2 个变体、时长由平台决定。**不要引导用户去找这些控件。**

## 二、参考歌曲 与 人声性别 冲突（官方 FAQ 原文口径）

官方 FAQ 明确：**同时提供「参考歌曲」和「人声性别」时，系统优先采用音频参考，人声性别设置可能不生效；
建议这两项只选其一。** 另有一类已知问题：即使没选音频参考，偶发人声性别与预期不符（官方称持续优化中）。

**写进交付的固定动作**：用户要用参考歌曲时，界面设置块里写「参考歌曲与人声性别二选一，
本次已按参考歌曲忽略性别选择」；没用参考歌曲时，写「人声性别：与风格栏一致」。

## 三、风格融合（官方 FAQ 鼓励的做法）

官方 FAQ 原文口径：Mureka **特别擅长风格融合**，「可以把不同风格关键词混在一起写——有时候意想不到的组合
反而能生成最有趣的结果」。官方给的模板三要素：**风格 / 曲风、氛围 / 情绪、场景或使用方式**。

**落到本技能**：官方三要素已并入风格栏七要素（情绪位 + 场景位）；融合写法与克制条款见
`@references/style-tokens.md` 第三节。

## 四、平台能力边界（FAQ + 实测）

| 能力 | 在哪 | 提示词怎么配合 |
|---|---|---|
| **Remix 哼唱旋律** | `+Remix` | 用户可录唱 / 传音频 / 贴链接提供旋律。有旋律参考时风格栏照写目标风格，**不要**在风格栏里描述旋律 |
| **自定义歌手** | `+自定义歌手` | 锁定人声一致性的唯一可靠手段。提示词里人声照常写，但**要在界面设置块注明「人声一致靠它」** |
| **Studio 改词保旋律** | 工作室版块 | 已生成的歌可改歌词、保留旋律与人声（账号是否可用以界面为准，**不提套餐与档位**）。本技能的改词交付可直接用于它 |
| **下载** | 生成结果页 | 能力与账号状态相关，**不提档位**；用户问就让他看界面 |

## 五、交付前必做的界面动作（必做类——交付包第三节逐条对应）

每次交付，界面设置块至少含以下各行（按本次路径取舍，**不准整块省略**）：

1. 模式：自定义
2. 人声性别：与风格栏一致；**若同时用参考歌曲 → 二者只留其一**
3. 歌名：≤50 字，可留空
4. 「⚠️ 本面板没有时长 / 版本数 / 人声参数滑杆，别去找」（有人声与器乐包都写）
5. 「⚠️ 别点风格栏的『增强』——它会改写你写好的英文风格 token」
6. 器乐 / 循环包：「打开纯音乐开关」
7. 用户提过「多首歌同一个人声」：「用 +自定义歌手，不靠提示词」

**为什么这是必做**：第 4、5、2 三条分别对应本技能最常被白找的控件、最常被误触的按钮、
最常被同时误用的两个开关——不说，用户就会在错误的地方花时间。
