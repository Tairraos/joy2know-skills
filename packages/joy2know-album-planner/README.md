# 音乐专辑设计师（joy2know-album-planner）

> 从「一句感觉」到「一整张专辑」 —— 音色锚点、专辑结构、差异矩阵、逐首粘贴清单与封面提示词，两份文件交付。

## 他解决什么问题

想做一张专辑，脑子里只有几段零散灵感，于是每首各写各的：

- BPM 全一样、调式全一样、主奏乐器也一样 —— 连着放像同一台机器出的货，不是一张专辑；
- 拍号与调式只写在曲目表里，**风格栏里根本没有** —— 那一轴是名义轴，生成时不生效；
- 副歌开口度不够，情绪顶不上去（闭口韵押出来的副歌就是喊不上去）；
- 纯音乐专辑打开了「纯音乐」开关，**歌词栏被锁死**，方括号编曲标签贴不进去，音乐流向失控；
- 曲名全是他随口编的，用户改一个就得整篇重排。

他站在**专辑成形之前**动手：一轮问答收齐九项 → **曲名没定先给候选** →
定音色锚点、排结构、算差异矩阵 → 逐首落成可粘贴文本 → 跑六道门禁。

## 三条底线

1. **只产出文本，交付两份文件。** 专辑规划文档 + 逐首粘贴清单，同一目录。
   不生成音频、不调用生成接口、不带账号与密钥。
2. **差异靠名词，不靠形容词。** 拍号 / 调式 / 主奏乐器 / 编制 / 音区 / BPM ——
   形容词会被模型平均掉，对每首都一样。六根轴里任意两首最多 2 根相同，BPM 必须全不同。
3. **结构校验由脚本算。** 校验器在 `skills/joy2know-album-design/scripts/album_check.py`，
   六条门禁 FAIL 修到零才交付；两份 md 都由生成脚本从同一份数据渲染，不手写。

## 擅长什么

- **差异矩阵**：六根轴逐对比对，超标指名道姓报出是哪两首、哪几根轴相同
- **拍号与调式**：不是表格里的两行数字，而是「这两行是什么意思、为什么配对、配对的纪律」
- **音色锚点**：把一句风格描述落成具体英文 token（空间感 / 编制 / 音区 / 力度纪律）
- **纯音乐专辑**：开关保持关闭 + 风格栏首句 `No vocals` + 全篇无人声词 +
  音乐流向靠歌词栏的 `Intro / Loop A / Loop B / Loop A2 / Loop C / End` 标签
- **封面提示词**：每首点名曲名 + 纤细手写体 + 留白位置，整张共用一组视觉母题
- **也会写单首的词**：专辑里某一首不想要了，走作词路径重写，其余不动

## 用法

直接说「帮我规划一张专辑」。**曲名没定他会先给你 3 组 × 5 个候选**，
你挑完（或自己说几个）他才排全篇。

改内容时**只改生成脚本里的数据再重跑** —— 他不让你手改那两份 md，
因为手改就是漂移的起点，你会粘到旧版。

## 边界

不做混音、母带、音频剪辑（无缝循环是**素材 + 后期裁剪**做出来的，裁切与接缝淡化在你的编辑器里做）；
不做封面图、不写 MV 脚本（给封面**提示词文本**，出图你自己做）；
不承诺生成效果 —— **整张专辑的统一性靠规划，不靠一次生成**。
